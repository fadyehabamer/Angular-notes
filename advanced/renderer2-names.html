Renderer2, name by nameRenderer2، اسم اسم

The idea behind Renderer2 is small: instead of touching the DOM yourself, you ask Angular’s renderer to do it, so the same code also runs on the server. The confusing part is the names. One small directive mixes Angular’s method names, the browser’s event names, HTML tag and attribute names, an ARIA word and a CSS class, most of them inside quotes where they all look the same. This page sorts out which of those words are yours, and which ones another file has to copy.الفكرة ورا Renderer2 صغيرة: بدل ما تلمس الـ DOM بإيدك، بتطلب من الـ renderer بتاع أنجولار يعملها، فنفس الكود يشتغل على السيرفر كمان. اللي بيلخبط هو الأسماء. directive صغير واحد بيخلط أسماء ميثودز أنجولار، وأسماء events المتصفح، وأسماء تاجات وattributes من HTML، وكلمة من ARIA، وكلاس CSS، وأغلبهم بين علامات تنصيص فشكلهم كلهم واحد. الصفحة دي بتفرز أنهي كلمة فيهم بتاعتك، وأنهي واحدة ملف تاني لازم ينسخها.
