NgRx SignalStore, name by nameNgRx SignalStore، اسم اسم

The idea: a library gives every store the same shape, so a big team writes state the same way. The confusing part is the names. signalStore is full of functions whose names start with with, you invent keys inside them, NgRx turns those keys into signals, and suddenly a word you typed once in withState is called as store.todos() in a template. This page follows each name from where you invent it to everywhere it has to match.الفكرة: المكتبة بتدّي كل store نفس الشكل، فالفريق الكبير بيكتب الحالة بنفس الطريقة. اللي بيلخبط هو الأسماء. signalStore مليان functions أسماءها بتبدأ بـ with، وانت بتخترع مفاتيح جواها، وNgRx بيحوّل المفاتيح دي لـ signals، وفجأة كلمة كتبتها مرة واحدة في withState بتتنادى كـ store.todos() في تمبلت. الصفحة دي ماشية ورا كل اسم من المكان اللي اخترعته فيه لحد كل مكان لازم يطابقه.
