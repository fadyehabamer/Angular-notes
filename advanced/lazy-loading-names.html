Lazy loading, name by nameالـ lazy loading، اسم اسم

The idea is simple: do not download a page’s code until somebody needs it, then fetch it quietly in the background before they click. The confusing part is the names. The single line import('./about').then(m => m.About) holds a file path, a parameter you can call anything, and a class name that must match another file exactly. Next to it sit a URL that every link must copy, route keys that are Angular’s, and a method name the router calls for you. This page sorts them out.الفكرة بسيطة: متنزّلش كود صفحة غير لما حد يحتاجها، وبعدين هاتها بهدوء في الخلفية قبل ما يدوس. اللي بيلخبط هو الأسماء. السطر الواحد import('./about').then(m => m.About) جواه مسار ملف، وparameter تسمّيه أي حاجة، واسم كلاس لازم يطابق ملف تاني بالظبط. وجنبه URL كل لينك لازم ينسخه، ومفاتيح route بتاعة أنجولار، واسم ميثود الـ router بيناديها بنفسه. الصفحة دي بتفرزهم.

BThe router calls preloadالـ router هو اللي بينادي preload

A strategy is a class the router calls, so it must have a method named exactly preload, taking a route and a load function and returning an Observable. The class name, SelectivePreload, is free; the method name is not.الاستراتيجية كلاس الـ router بيناديه، فلازم يبقى فيها ميثود اسمها preload بالظبط، بتاخد route وfunction للتحميل وبترجّع Observable. اسم الكلاس، SelectivePreload، براحتك؛ لكن اسم الميثود لأ.

CLinks copy the pathاللينكات بتنسخ الـ path

The path of a lazy route is yours, but it becomes public the moment a link, a bookmark or a search engine uses it. Inside the app, every routerLink must copy it. Outside the app, people’s saved links do too, so renaming a URL has a cost you cannot see in the code.الـ path بتاع الـ route الـ lazy بتاعك، بس بيبقى عام أول ما لينك أو bookmark أو محرك بحث يستخدمه. جوه التطبيق، كل routerLink لازم ينسخه. وبرّه التطبيق، اللينكات اللي الناس حافظاها برضه، فتغيير الـ URL ليه تمن مش باين في الكود.
