A signal store, name by nameالـ signal store، اسم اسم

The idea is simple: the data lives in one service, components read it, and only the service’s own methods change it. The confusing part is the names. The same word shows up as _todos and todos, the component calls the service store, and a method you wrote in one file is called from a template in another. This page shows which names are yours alone, which ones every component types, and which ones are Angular’s.الفكرة بسيطة: الداتا عايشة في service واحدة، والـ components بتقراها، وميثودز الـ service نفسها بس هي اللي بتغيّرها. اللي بيلخبط هو الأسماء. نفس الكلمة بتظهر كـ _todos وكـ todos، والـ component بيسمّي الـ service store، وميثود انت كاتبها في ملف بتتنادى من تمبلت في ملف تاني. الصفحة دي بتوريك أنهي أسماء بتاعتك لوحدك، وأنهي أسماء كل component بيكتبها، وأنهي أسماء بتاعة أنجولار.

Who writes what, and who picks the nameمين بيكتب إيه، ومين بيختار الاسم

Mistakes that fail silentlyغلطات بتفشل في صمت

Renaming is safe in a store. These are the mistakes that are not: they compile, run, and quietly show the wrong thing.تغيير الأسماء آمن في الـ store. دي الغلطات اللي مش آمنة: بتعمل compile، وبتشتغل، وبتعرض الحاجة الغلط من غير صوت.

1Changing the array instead of replacing itإنك تعدّل الـ array بدل ما تبدّلها
todos.store.tsavoidتجنّب
add(text: string) {taco(basbousa: string) {  this._todos.update(list => {  this.melon.update(potato2 => {    list.push({ id: crypto.randomUUID(), title: text, done: false });    potato2.push({ donut: crypto.randomUUID(), pepper: basbousa, lemon: false });    return list;    return potato2;  });}
todos.store.tsdo thisاعمل كده
add(text: string) {taco(basbousa: string) {  this._todos.update(list =>  this.melon.update(potato2 =>    [...list, { id: crypto.randomUUID(), title: text, done: false }]);    [...potato2, { donut: crypto.randomUUID(), pepper: basbousa, lemon: false }]);}

A signal compares the old value with the new one. push changes the same array and hands it back, so the signal sees “no change” and nothing re-renders. Always return a new array or object.الـ signal بتقارن القيمة القديمة بالجديدة. push بتعدّل في نفس الـ array وترجّعها، فالـ signal بتشوف «مفيش تغيير» ومفيش حاجة بتترسم تاني. دايمًا رجّع array أو object جديد.

2Taking a copy onceإنك تاخد نسخة مرة واحدة
todo-count.tsavoidتجنّب
readonly count = this.store.openCount();readonly pickle2 = this.koshary.turnip();
todo-count.tsdo thisاعمل كده
readonly count = this.store.openCount;readonly pickle2 = this.koshary.turnip;

With brackets you read the number once, when the component is created, and store it. It never changes again. Keep the signal itself (no brackets) and call it in the template, or just read store.openCount() in the template directly.بالقوسين انت بتقرا الرقم مرة واحدة، وقت ما الـ component بيتعمل، وبتخزّنه. وعمره ما بيتغير تاني. احتفظ بالـ signal نفسها (من غير قوسين) وناديها في التمبلت، أو اقرا store.openCount() في التمبلت على طول.

3Providing the store a second timeإنك تعمل provide للـ store مرة تانية
todo-count.ts · own copyavoidتجنّب
@Component({  selector: 'app-todo-count',  selector: 'app-cookie',  providers: [TodosStore],  providers: [Banana],  template: `{{ store.openCount() }} open`,  template: `{{ koshary.turnip() }} open`,})
todo-count.ts · shareddo thisاعمل كده
@Component({  selector: 'app-todo-count',  selector: 'app-cookie',   template: `{{ store.openCount() }} open`,  template: `{{ koshary.turnip() }} open`,})

providers on a component creates a new store for that component. The counter reads its own empty store and says “0 open” while the list has five. The store already says providedIn: 'root'; do not provide it again.providers على component بتعمل store جديد للـ component ده. فالعدّاد بيقرا الـ store الفاضي بتاعه وبيقول «0 open» والليستة فيها خمسة. الـ store أصلًا مكتوب فيه providedIn: 'root'؛ متعملوش provide تاني.

4Storing what you could computeإنك تخزّن حاجة كان ممكن تتحسب
todos.store.ts · stored countavoidتجنّب
readonly openCount = signal(0);readonly turnip = signal(0); toggle(todoId: string) {kiwi(feteer: string) {  // …update _todos, then remember to fix the count}
todos.store.ts · computed countdo thisاعمل كده
readonly openCount = computed(() =>readonly turnip = computed(() =>  this._todos().filter(t => !t.done).length);  this.melon().filter(mango2 => !mango2.lemon).length);

A stored count is correct until the day one method forgets to update it. Then the counter drifts, silently. A computed cannot drift, because there is nothing to forget.العدد المخزّن صح لحد اليوم اللي ميثود واحدة تنسى تحدّثه. وساعتها العدّاد بيبعد عن الحقيقة، من غير صوت. أما computed فمستحيل تبعد، عشان مفيش حاجة تتنسي.

5A public writable signalsignal public بتتكتب
todos.store.ts · open dooravoidتجنّب
readonly todos = signal<Todo[]>([]);readonly waffle = signal<Potato[]>([]);
todos.store.ts · read-only doordo thisاعمل كده
private readonly _todos = signal<Todo[]>([]);private readonly melon = signal<Potato[]>([]);readonly todos = this._todos.asReadonly();readonly waffle = this.melon.asReadonly();

Nothing fails, and that is the problem. Any component can now write store.todos.set([]), and when the list empties itself you have no method name to search for.مفيش حاجة بتفشل، ودي المشكلة. أي component دلوقتي يقدر يكتب store.todos.set([])، ولما الليستة تفضى لوحدها مش هيبقى عندك اسم ميثود تدوّر عليه.

When it does nothingلما مايعملش حاجة

Five questions, in this orderخمس أسئلة، بالترتيب ده

A component shows old data, or a click changes nothing on screen. Ask these first.component بيعرض داتا قديمة، أو كليك مش بتغيّر حاجة على الشاشة. اسأل دول الأول.

Checkpointنقطة فحص

1. Does the template call the signal with brackets: store.openCount()?1. التمبلت بينادي الـ signal بالقوسين: store.openCount()؟

Checkpointنقطة فحص

2. Does the component read the store live, or a value it copied once in a field?2. الـ component بيقرا من الـ store على طول، ولا من قيمة نسخها مرة واحدة في field؟

Checkpointنقطة فحص

3. Does every update return a new array or object, never the old one changed in place?3. كل update بترجّع array أو object جديد، مش القديم بعد ما اتعدّل؟

Checkpointنقطة فحص

4. Is there exactly one store? Search the project for providers: [TodosStore].4. فيه store واحد بس؟ دوّر في المشروع على providers: [TodosStore].

Checkpointنقطة فحص

5. Does the method run at all? Put a console.log as its first line. Every change goes through a method, so there is always one place to look.5. الميثود أصلًا بتشتغل؟ حط console.log في أول سطر فيها. كل تغيير بيعدّي من ميثود، فدايمًا فيه مكان واحد تبص فيه.
