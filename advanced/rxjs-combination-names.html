forkJoin and combineLatest, name by nameforkJoin وcombineLatest، اسم اسم

The idea: you have several streams and want one answer. forkJoin waits for all of them to finish, combineLatest answers again whenever any of them changes, and withLatestFrom lets one of them decide when. The confusing part is the names on the way out: object keys you invented, tuple slots you name however you like, a leading comma that skips a slot, and query keys that belong to the server. This page shows who owns each one.الفكرة: عندك كذا stream وعايز إجابة واحدة. forkJoin بتستنى كلهم يخلصوا، وcombineLatest بترد تاني كل ما أي واحد فيهم يتغير، وwithLatestFrom بتخلي واحد منهم هو اللي يقرر إمتى. اللي بيلخبط هو الأسماء وهي خارجة: مفاتيح object انت ألّفتها، وخانات tuple بتسمّيها زي ما تحب، وفاصلة في الأول بتنط خانة، ومفاتيح query بتاعة السيرفر. الصفحة دي بتوريك مين صاحب كل واحد.

BThe array order is the only thing that mattersترتيب الـ array هو الحاجة الوحيدة اللي فارقة

CThe server names the queryالسيرفر هو اللي بيسمّي الـ query

{ q: f.search, sort: f.sort } maps your names onto the server’s. Keep that mapping in the service, in one place. If you ever write { params: { ...f } }, your field names become the query keys and every rename of search quietly breaks the search.{ q: f.search, sort: f.sort } بتنقل أسماءك لأسماء السيرفر. خلّي النقلة دي في السيرفس، في مكان واحد. لو كتبت في يوم { params: { ...f } }، أسماء الحقول بتاعتك هتبقى مفاتيح الـ query وأي تغيير لـ search هيبوّظ البحث في صمت.

The signal versionنسخة الـ signals

Streams vs signals: the same join, fewer namesstreams قصاد signals: نفس الجمع، أسماء أقل

combineLatest exists because a stream has no current value. Signals do, so “combining” is just reading two of them in one function. You will see both styles; the names you own shrink to the signals themselves.combineLatest موجودة عشان الـ stream مالوش قيمة حالية. الـ signals ليها، فـ «الجمع» بقى مجرد إنك تقرا اتنين منهم في function واحدة. هتشوف الأسلوبين؛ والأسماء اللي بتاعتك بتقل لحد الـ signals نفسها.

Five questions, in this orderخمس أسئلة، بالترتيب ده

Your combined stream “never fires”, or fires with the wrong values. Ask these first.الـ stream المجمّع بتاعك «عمره ما بيشتغل»، أو بيشتغل بقيم غلط. اسأل دول الأول.
