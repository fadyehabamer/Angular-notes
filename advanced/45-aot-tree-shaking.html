AOT compilation and tree shakingكمبايل AOT والـ tree shaking

Your templates are not HTML at runtime — the compiler turns them into JavaScript functions before the browser ever sees them. Understanding that explains why templates are type-checked, why the Angular compiler is not shipped to users, and why one careless import can defeat tree shaking.التمبلتس بتاعتك مش HTML وقت التشغيل — الـ compiler بيحوّلهم لدوال جافاسكريبت قبل ما البراوزر يشوفهم أصلاً. وفهم ده بيشرح ليه التمبلتس بيتفحص نوعها، وليه compiler أنجولار مش بيتشحن للمستخدمين، وليه import واحد مهمل بيلغي الـ tree shaking.

What it actually isهي إيه بالظبط

AOT compiles your templates before shipping, and tree shaking throws away code nobody imports.الـ AOT بيترجم الـ templates قبل الشحن، والـ tree shaking بيرمي الكود اللي محدش بيستورده.

Think of it likeاعتبرها زي

Packing for a trip. AOT is folding everything at home instead of at the airport. Tree shaking is leaving the coat behind.لما تحزم شنطة سفر. الـ AOT إنك تطوي كل حاجة في البيت مش في المطار. والـ tree shaking إنك تسيب البالطو.

You reach for it whenهتحتاجها لما

It is already on. What matters is not accidentally defeating it.هو شغال أصلاً. المهم إنك ماتعطّلوش من غير قصد.

The whole idea in 4 picturesالفكرة كلها في 4 صور

Templates become codeالـ templates بتبقى كود

Your HTML is turned into TypeScript functions at build time, then type-checked.الـ HTML بتاعك بيتحوّل لدوال TypeScript وقت البناء، وبعدين بيتفحص نوعياً.

Real errors surfaceالأخطاء الحقيقية بتطلع

A typo in a binding becomes a build failure instead of a blank space at runtime.غلطة إملائية في binding بتبقى فشل بناء بدل مساحة فاضية وقت التشغيل.

Unused code is droppedالكود غير المستخدم بيتشال

Static import statements are what make this possible. Dynamic tricks defeat it.جُمل import الثابتة هي اللي بتخلي ده ممكن. الحيل الديناميكية بتعطّله.

Side effects surviveالآثار الجانبية بتنجو

A module that does work on import cannot be shaken out. Keep modules quiet.موديول بيعمل شغل وقت الاستيراد مايتشالش. خلي الموديولات ساكتة.

Real exampleمثال حقيقي The barrel file that cost 180 kBملف الـ barrel اللي كلّف 180 كيلو

Barrel files feel tidy and quietly ruin tree shaking. Importing one symbol from a barrel pulls in the whole barrel, and every module it re-exports comes with it — including the chart library you use on one admin page.ملفات الـ barrel شكلها مرتب وبتخرّب الـ tree shaking في هدوء. وعمل import لرمز واحد من barrel بيجيب الـ barrel كله، وكل module بيعيد تصديره بييجي معاه — بما فيها مكتبة الرسوم اللي بتستخدمها في صفحة أدمن واحدة.

the tidy-looking versioncosts 180 kBبتكلف 180 كيلو
// src/app/ui/index.ts — the barrelexport * from './button';export * from './card';export * from './chart';      // ← imports a 180 kB charting libexport * from './table'; // src/app/home/home.tsimport { Button } from '../ui';    // I only want Button… // …but the bundler must evaluate ./ui/index.ts, which imports// ./chart, which imports the charting library. it is now in// your main bundle, on the home page, for every visitor.
the fiximport the fileاعمل import للملف

Watch outخد بالك

  • AOT has been the only mode since Angular 9. If a tutorial talks about “switching on AOT”, it predates 2020 and the rest of it is probably stale too.الـ AOT هو الوضع الوحيد من أنجولار 9. ولو شرح بيتكلم عن «تشغيل الـ AOT»، يبقى من قبل 2020 وباقيه غالباً قديم كمان.
  • Barrel files defeat tree shaking. Import the specific file, or set "sideEffects": false so the bundler is allowed to drop the rest.ملفات الـ barrel بتلغي الـ tree shaking. اعمل import للملف المحدد، أو حط "sideEffects": false عشان الـ bundler يسمح لنفسه يمسح الباقي.
  • A class in a providers array can never be tree-shaken — the array references it. providedIn: 'root' can be.الكلاس اللي في مصفوفة providers مستحيل يتشذّب — المصفوفة بتشير له. أما providedIn: 'root' فينفع.
  • Top-level side effects (console.log, assigning to window) make a whole module unshakeable. Keep module scope pure.الآثار الجانبية في أعلى الملف (console.log أو الإسناد لـ window) بتخلي الـ module كله غير قابل للشذب. خلي نطاق الـ module نضيف.
  • Never diagnose bundle size from a dev build. Only --configuration production minifies and tree shakes.عمرك ما تشخّص حجم الـ bundle من build تطوير. --configuration production بس هو اللي بيصغّر ويشذّب.
If you remember one thingلو هتفتكر حاجة واحدة

Template errors that only appear in ng build are AOT finding real bugs that dev mode was hiding.أخطاء الـ template اللي بتظهر بس في ng build دي AOT بيلاقي مشاكل حقيقية كان وضع التطوير مخبّيها.

Q01 What does the AOT compiler produce from your template?مترجم الـ AOT بيطلع إيه من الـ template بتاعك؟
whyليه

Templates are compiled at build time, so the browser never ships a template compiler and template errors surface during ng build rather than at runtime.الـ templates بتتترجم وقت البناء، فالمتصفح مبياخدش مترجم templates خالص وأخطاء الـ template بتظهر وقت ng build مش وقت التشغيل.

Q02 What stops tree-shaking from removing dead code?إيه اللي بيمنع الـ tree-shaking من إنه يشيل الكود الميت؟
whyليه

The bundler must be able to prove nothing is used. Top-level code with side effects, or a lookup like obj[name], defeats that proof — so everything is kept just in case.الـ bundler لازم يقدر يثبت إن مفيش حاجة مستخدمة. والكود على المستوى الأعلى اللي له تأثيرات جانبية، أو بحث زي obj[name]، بيهزم الإثبات ده — فبيتم الاحتفاظ بكل حاجة تحوّطاً.

Q03 Why do standalone components help bundle size?ليه الـ components المستقلة بتساعد في حجم الحزمة؟
whyليه

An NgModule declared everything together, so importing one component dragged its module's whole surface along. With imports on the component, the graph is precise and much easier to shake.الـ NgModule كان بيعلن كل حاجة مع بعض، فأي import لـ component واحد كان بيجرّ سطح الموديول كله معاه. ومع imports على الـ component، الرسم البياني بيبقى دقيق وأسهل بكتير في التقليم.

Q04 Which tells you what actually ended up in the bundle?أنهي واحدة بتقولك إيه اللي وصل فعلاً للحزمة؟
whyليه

The stats file maps every byte back to the module it came from, which is how you find the one date library nobody meant to ship. The profiler answers a different question: what runs.ملف الإحصائيات بيربط كل بايت بالموديول اللي جه منه، وده إزاي تلاقي مكتبة التواريخ اللي محدش كان قاصد ينشرها. أما الـ profiler فبيجاوب على سؤال تاني: إيه اللي بيشتغل.
