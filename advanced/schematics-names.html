Schematics, name by nameالـ schematics، اسم اسم

The idea is simple: a command name points at a function, and the function writes files from templates. The confusing part is the names. name alone means three different things in the same small package, the word feature shows up as a command, a folder and a function, and the links between them are strings that TypeScript never sees. This page untangles every one.الفكرة بسيطة: اسم أمر بيشاور على function، والـ function بتكتب ملفات من قوالب. اللي بيلخبط هو الأسماء. كلمة name لوحدها معناها تلات حاجات مختلفة في نفس الباكدج الصغيرة، وكلمة feature بتظهر كأمر وكفولدر وكـ function، والروابط اللي بينهم strings عمر TypeScript ما بيشوفها. الصفحة دي بتفك كل واحدة فيهم.

  • The command line never reaches your function directly. It goes package → collection → #export. If any link is wrong, your function is never called.سطر الأوامر عمره ما بيوصل للـ function بتاعتك على طول. هو بيمشي باكدج ← collection ← #export. لو أي رابط غلط، الـ function بتاعتك عمرها ما هتتنادى.
  • Option names live in three places: schema.json, the options type in TypeScript, and the templates. The type is only your promise; TypeScript cannot compare it with the JSON.أسماء الـ options عايشة في تلات أماكن: schema.json، والـ type بتاع options في TypeScript، والقوالب. والـ type ده مجرد وعد منك؛ TypeScript مايقدرش يقارنه بالـ JSON.
  • A template only knows what you hand it. It has no access to your factory’s variables. Every name on this page — yours or Angular’s?كل اسم في الصفحة دي — بتاعك ولا بتاع أنجولار؟

Read the orange rows first. In a schematic most shared names are joined by strings: a file path, a #export after a path, a key in schema.json. TypeScript checks none of them, so a mismatch only shows up when someone runs ng generate. Everything imported from @angular-devkit is fixed.اقرا الصفوف البرتقاني الأول. في الـ schematic أغلب الأسماء المتشاركة متوصّلة بـ strings: مسار ملف، أو #export بعد مسار، أو مفتاح في schema.json. TypeScript مابيشيّكش ولا واحدة فيهم، فأي اختلاف بيظهر بس لما حد يشغّل ng generate. وأي حاجة جاية من @angular-devkit ثابتة.

AThe template file name syntaxطريقة كتابة أسماء ملفات القوالب

A file name like __name@dasherize__.ts.template has three fixed parts: double underscores around a value, @ before a helper to apply, and the .template suffix. Only the words inside are names, and they must be keys you passed to applyTemplates: name from your options, dasherize from strings. The suffix also keeps TypeScript from compiling your templates as source.اسم ملف زي __name@dasherize__.ts.template فيه تلات حتت ثابتة: underscore مزدوجة حوالين القيمة، و@ قبل الـ helper اللي هيتطبّق، واللاحقة .template. الكلمات اللي جوه بس هي الأسماء، ولازم تكون مفاتيح انت بعتّها لـ applyTemplates: name من الـ options بتاعتك، وdasherize من strings. واللاحقة كمان بتمنع TypeScript إنه يكومبايل القوالب كأنها كود.
