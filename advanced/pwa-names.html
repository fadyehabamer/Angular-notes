The service worker, name by nameالـ service worker، اسم اسم

The idea is simple: a script sits between your app and the network, and you tell it what to cache in a JSON file. The confusing part is the names. They are spread over five files and three formats, most of them belong to Angular or to the browser, and a misspelt key usually does not fail: it just is not read. This page shows which few names are yours, and which ones must match across files.الفكرة بسيطة: سكريبت بيقعد بين تطبيقك والشبكة، وانت بتقوله يكاش إيه في ملف JSON. اللي بيلخبط هو الأسماء. متوزعة على خمس ملفات وتلات أنواع، وأغلبها بتاع أنجولار أو المتصفح، والمفتاح المكتوب غلط غالبًا مابيفشلش: هو بس مابيتقريش. الصفحة دي بتوريك أنهي أسماء قليلة بتاعتك، وأنهي أسماء لازم تبقى زي بعض في كذا ملف.

  1. 1angular.jsonthe build · readsالـ build · بيقرا
    "serviceWorker": "ngsw-config.json""serviceWorker": "cache-policy.json"

    The build option serviceWorker is Angular’s. Its value is the name of your config file, ngsw-config.json. The two must match. The build then copies ngsw-worker.js into dist and writes a file list for the worker.الـ option serviceWorker بتاع أنجولار. وقيمته اسم ملف الإعدادات بتاعك، ngsw-config.json. الاتنين لازم يبقوا زي بعض. وبعدين الـ build بينسخ ngsw-worker.js في dist وبيكتب ليستة ملفات للـ worker.

  2. 2ngsw-config.jsonyou · the policyانت · السياسة
    "name": "api-fresh","name": "api-turnip","urls": ["/api/**"],"cacheConfig": { "strategy": "freshness", "timeout": "3s" }

    Every key here is Angular’s: urls, cacheConfig, strategy. So is the value freshness. The only word you invented is the group name api-fresh, and nothing else in the app refers to it.كل مفتاح هنا بتاع أنجولار: urls، cacheConfig، strategy. والقيمة freshness كمان. الكلمة الوحيدة اللي انت ألّفتها هي اسم الجروب api-fresh، ومفيش حاجة تانية في التطبيق بتشاور عليه.

  3. 3app.config.tsthe app · registersالتطبيق · بيسجّل
    provideServiceWorker('ngsw-worker.js', {  enabled: !isDevMode(),})

    The app registers the worker file by its fixed name. enabled: !isDevMode() means the worker never runs under ng serve. Remember that before you decide it is broken.التطبيق بيسجّل ملف الـ worker باسمه الثابت. وenabled: !isDevMode() معناها إن الـ worker عمره ما بيشتغل مع ng serve. افتكر ده قبل ما تقرر إنه بايظ.

The only names that must match across your files are the config file name, the manifest file name, and the members your template reads (ready, reload, online).الإعدادات: مفاتيح أنجولار، وقيمك انت. الكود: SwUpdate بتاع أنجولار، والـ service بتاعتك حواليه. والأسماء الوحيدة اللي لازم تبقى زي بعض بين ملفاتك انت هي اسم ملف الإعدادات، واسم ملف الـ manifest، والحاجات اللي التمبلت بتاعك بيقراها (ready، reload، online).

The TypeScript names behave like everywhere else: a missed rename is a compile or build error. The file names and JSON values are different. The compiler never reads them, so a mistake there shows up at runtime, or not at all.أسماء الـ TypeScript بتتصرف زي أي حتة تانية: لو نسيت تغيّر اسم، هتاخد compile أو build error. لكن أسماء الملفات وقيم الـ JSON حاجة تانية. الكومبايلر عمره ما بيقراها، فالغلطة فيها بتظهر وقت التشغيل، أو مابتظهرش خالص.

Mistakes that fail silentlyغلطات بتفشل في صمت

A service worker that is not doing its job looks exactly like an app without one. The page loads, the data shows. That is why these mistakes survive so long.الـ service worker اللي مش بيعمل شغله شكله بالظبط زي تطبيق مافيهوش واحد. الصفحة بتحمّل، والداتا بتظهر. وعشان كده الغلطات دي بتعيش فترة طويلة.

1Nobody injects the update serviceمحدش بيعمل inject لـ service التحديثات
app.ts · forgot itavoidتجنّب
export class App {  readonly network = inject(Network);  readonly kiwi = inject(Pickle);}
app.ts · injects itdo thisاعمل كده
export class App {  readonly updates = inject(Updates);  readonly taco = inject(Banana);  readonly network = inject(Network);  readonly kiwi = inject(Pickle);}

A providedIn: 'root' service is created the first time something injects it. If nothing does, its constructor never runs, nobody subscribes to versionUpdates, and the banner never appears. Users keep the old version. No error anywhere.الـ service اللي providedIn: 'root' بيتعمل أول مرة حد يعمله inject. لو محدش عمل، الـ constructor بتاعه عمره ما هيشتغل، ومحدش هيعمل subscribe لـ versionUpdates، والشريط عمره ما هيظهر. والناس هتفضل على النسخة القديمة. ومفيش أي error.

3Removing a listener you never addedإنك تشيل listener عمرك ما ضفته
network.ts · inlineavoidتجنّب
addEventListener('online', () => this.online.set(true));addEventListener('online', () => this.waffle.set(true));// later:removeEventListener('online', () => this.online.set(true));removeEventListener('online', () => this.waffle.set(true));

The browser removes a listener by comparing the function itself, not its text. Two arrow functions that look the same are two different functions, so the left version removes nothing. Giving the handler a name, on, is what lets you pass the same one twice.المتصفح بيشيل الـ listener بإنه يقارن الـ function نفسها، مش الكلام المكتوب. اتنين arrow functions شكلهم زي بعض يبقوا اتنين functions مختلفين، فالنسخة اللي على الشمال مابتشيلش حاجة. إنك تدّي الـ handler اسم، on، هو اللي بيخليك تبعت نفس الواحدة مرتين.

4A URL pattern that never matchespattern للـ URL عمره ما بيطابق

"urls": ["/api/**"]
ngsw-config.json · full addressdo thisاعمل كده
"urls": ["https://api.shop.example/**"]

If your API lives on another domain, a pattern that starts with /api only covers your own origin. The requests go straight to the network, nothing is cached, and offline the list is simply empty. Write the address the app really calls.لو الـ API بتاعك على domain تاني، الـ pattern اللي بيبدأ بـ /api بيغطي الـ origin بتاعك بس. الريكويستات بتروح للشبكة على طول، ومفيش حاجة بتتكاش، ومن غير نت الليستة بتبقى فاضية وخلاص. اكتب العنوان اللي التطبيق بينادي عليه فعلًا.

5Cache-first on data that changesالكاش الأول على داتا بتتغير

"urls": ["/api/prices"],"cacheConfig": { "strategy": "performance", "maxAge": "7d" }
ngsw-config.json · pricesdo thisاعمل كده
"urls": ["/api/prices"],"cacheConfig": { "strategy": "freshness", "maxAge": "1h", "timeout": "3s" }

performance answers from the cache without asking the server while the entry is younger than maxAge. The prices look perfectly normal, they are just a week old. Use freshness unless the data really is static.performance بيرد من الكاش من غير ما يسأل السيرفر طول ما الرد أصغر من maxAge. الأسعار شكلها طبيعي خالص، بس عمرها أسبوع. استخدم freshness إلا لو الداتا ثابتة فعلًا.
