@defer, name by name@defer، اسم اسم

The idea is simple: wrap part of a template in @defer, and its code is downloaded later, when a trigger fires. The confusing part is the names. The line @defer (on viewport; prefetch on idle) is five words, and all of them are Angular’s. Inside the block, the component looks completely normal. And at the top of the file you still write a normal import, which looks like it should load everything straight away. This page sorts out which words are yours and which are fixed.الفكرة بسيطة: لف جزء من التمبلت في @defer، والكود بتاعه يتنزّل بعدين، لما trigger يحصل. اللي بيلخبط هو الأسماء. السطر @defer (on viewport; prefetch on idle) خمس كلمات، وكلهم بتوع أنجولار. وجوه البلوك، الـ component شكله عادي خالص. وفوق في الملف لسه بتكتب import عادي، شكله كده المفروض يحمّل كل حاجة على طول. الصفحة دي بتفرز أنهي كلمات بتاعتك وأنهي ثابتة.

  5. 5product-page.htmlpage · the real thingالصفحة · الحاجة الحقيقية
