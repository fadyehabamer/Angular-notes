ControlValueAccessorControlValueAccessor

You built a nice star-rating component. Now someone wants it inside a reactive form with formControlName — and it does not work, because Angular has no idea how to read or write your component. ControlValueAccessor is the four-method contract that teaches it.عملت component حلو للتقييم بالنجوم. ودلوقتي حد عايزه جوه reactive form بـ formControlName — ومش شغال، لإن أنجولار مش عارف يقرا ولا يكتب في الـ component بتاعك. وControlValueAccessor هو العقد بأربع methods اللي بيعلّمه.

What it actually isهي إيه بالظبط

ControlValueAccessor is the interface that makes your own component work inside a form like a native input.ControlValueAccessor هي الواجهة اللي بتخلي الـ component بتاعك يشتغل جوه فورم زي أي input عادي.

Think of it likeاعتبرها زي

A universal plug adapter. Your device is unusual; the adapter makes the socket believe it is normal.محوّل فيشة عالمي. جهازك غريب، والمحوّل بيخلي الفيشة تفتكره عادي.

You reach for it whenهتحتاجها لما

A star rating, a colour picker, a tag input — anything you want to use with formControlName.تقييم بالنجوم، أو منتقي ألوان، أو خانة وسوم — أي حاجة عايز تستعملها مع formControlName.

The whole idea in 4 picturesالفكرة كلها في 4 صور

The form pushes a value in. Store it; do not emit anything back.الفورم بيدفع قيمة جواك. خزّنها، وماتطلقش أي حاجة للخارج.

onChange: you to formonChange: منك للفورم

Call the callback they registered whenever the user changes something.نادي الـ callback اللي سجّلوها كل ما المستخدم يغيّر حاجة.

This is what makes required errors appear at the right moment.دي اللي بتخلي أخطاء مطلوب تظهر في اللحظة الصح.

star-rating.component.tsthe four methodsالأربع methods
import { ControlValueAccessor, NG_VALUE_ACCESSOR } from '@angular/forms'; @Component({  selector: 'app-star-rating',  templateUrl: './star-rating.component.html',  providers: [{    provide: NG_VALUE_ACCESSOR,    useExisting: forwardRef(() => StarRating),   // forwardRef: the class    multi: true,                                  // is not defined yet  }],})export class StarRating implements ControlValueAccessor {  readonly max = input(5);  protected readonly value = signal(0);  protected readonly disabled = signal(false);   // Angular hands us these two. we call them; we never define them.  private onChange: (v: number) => void = () => {};  private onTouched: () => void = () => {};   // 1. the FORM writes INTO us (initial value, patchValue, reset)  writeValue(v: number | null) { this.value.set(v ?? 0); }   // 2. Angular gives us the callback to report changes  registerOnChange(fn: (v: number) => void) { this.onChange = fn; }   // 3. and the one to report 'the user has been here and left'  registerOnTouched(fn: () => void) { this.onTouched = fn; }   // 4. the form tells us it was disabled  setDisabledState(isDisabled: boolean) { this.disabled.set(isDisabled); }   // and this is us, reporting OUT  pick(n: number) {    if (this.disabled()) return;    this.value.set(n);    this.onChange(n);      // ← the form control now holds n    this.onTouched();      // ← and is marked touched  }}

Real exampleمثال حقيقي A currency input that stores centsخانة عملة بتخزّن قروش

The user sees "1,250.00"; the form holds 125000 as an integer, because storing money as a float is how rounding bugs get into invoices. The component is the translation layer, and every consumer gets it for free.المستخدم بيشوف «1,250.00»؛ والفورم ماسك 125000 كعدد صحيح، لإن تخزين الفلوس كـ float هو إزاي باجات التقريب بتدخل الفواتير. والـ component هو طبقة الترجمة، وكل مستخدم بياخدها ببلاش.

money-input.component.tsthe translationالترجمة
export class MoneyInput implements ControlValueAccessor {  protected readonly text = signal('');  private onChange: (v: number) => void = () => {};  private onTouched = () => {};   // form (cents) → screen (formatted)  writeValue(cents: number | null) {    this.text.set(cents == null ? '' : (cents / 100).toFixed(2));  }   // screen (typed) → form (cents)  onInput(raw: string) {    this.text.set(raw);    const n = Number(raw.replace(/[^0-9.]/g, ''));    this.onChange(Number.isFinite(n) ? Math.round(n * 100) : 0);  }   onBlur() {    this.onTouched();    const n = Number(this.text().replace(/[^0-9.]/g, ''));    if (Number.isFinite(n)) this.text.set(n.toFixed(2));   // tidy up  }   registerOnChange(fn: (v: number) => void) { this.onChange = fn; }  registerOnTouched(fn: () => void) { this.onTouched = fn; }  setDisabledState(d: boolean) { this.disabled.set(d); }}

Watch outخد بالك

  • Forgetting to call onChange() is the number one bug: the UI updates, the form control stays empty, and validation never passes.نسيان نداء onChange() هو الباج رقم واحد: الواجهة بتتحدث، والـ form control بيفضل فاضي، والـ validation عمره ما بينجح.
  • Never call onChange() from inside writeValue(). That is the form telling you — reporting it back creates an infinite loop.عمرك ما تنادي onChange() من جوه writeValue(). دي الفورم بيقول لك — والتبليغ راجع بيعمل حلقة لا نهائية.
  • Implement setDisabledState. Without it form.disable() has no effect on your control, which is a real accessibility and data-integrity bug.نفّذ setDisabledState. ومن غيرها form.disable() مالهاش تأثير على الـ control بتاعك، وده باج حقيقي في الإتاحة وسلامة البيانات.
  • forwardRef is required because the class is referenced on a line inside its own decorator, before it exists. Omitting it throws at startup.forwardRef مطلوبة لإن الكلاس بيتذكر في سطر جوه الـ decorator بتاعه، قبل ما يبقى موجود. ونسيانها بترمي ايرور عند التشغيل.
  • Call onTouched() on blur, not on change. Otherwise validation messages appear while the person is still typing the first character.نادي onTouched() عند الـ blur، مش عند التغيير. وإلا رسايل الـ validation هتظهر والشخص لسه بيكتب أول حرف.
If you remember one thingلو هتفتكر حاجة واحدة

Four methods, and the one everybody forgets is setDisabledState. Without it your control ignores disable() entirely.أربع ميثودز، واللي الكل بينساها هي setDisabledState. من غيرها الخانة بتاعتك بتتجاهل disable() خالص.
