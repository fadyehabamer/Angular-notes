NgRx, SignalStore and friendsNgRx و SignalStore وأخواتهم

State libraries buy you two things: an enforced convention across a large team, and a devtools timeline that answers “why did this change?”. They cost bundle size and ceremony. Know what you are buying before you adopt one — and know that most apps genuinely do not need it.مكتبات الحالة بتشتري لك حاجتين: convention مفروض على فريق كبير، وخط زمني في الـ devtools بيجاوب على «ليه ده اتغير؟». وتمنهم حجم bundle ومراسم. اعرف بتشتري إيه قبل ما تعتمد واحدة — واعرف إن معظم التطبيقات فعلاً مش محتاجاها.

choosing honestlythe real adviceالنصيحة الحقيقية
// PLAIN SIGNAL SERVICE     0 kB    — the default. most apps.//   → start here. always. you can migrate later. // NGRX SIGNALSTORE      ~ 8 kB    — convention, minimal ceremony//   → a team that wants one agreed shape for every store // NGRX STORE (Redux)    ~ 25 kB   — actions, devtools, time travel//   → large teams, complex flows, or you genuinely need the timeline // NGXS                  ~ 15 kB   — class-based, less boilerplate//   → smaller community; fine, but check its release cadence // THE HONEST ADVICE:// do not adopt a state library because the app 'feels big'.// adopt it when you can name the specific problem it solves// for you. otherwise you have bought ceremony and paid in kB.

Watch outخد بالك

  • Do not adopt a state library because the app “feels big”. Adopt it when you can name the problem it solves — usually “I cannot trace why this changed”.متعتمدش مكتبة حالة عشان التطبيق «حاسس إنه كبير». اعتمدها لما تقدر تسمّي المشكلة اللي بتحلها — وغالباً بتبقى «مش عارف أتتبع ليه ده اتغير».
  • Never put derived data in the store. Compute it in a selector or a computed — a stored total is a stored bug.عمرك ما تحط داتا مشتقة في الـ store. احسبها في selector أو computed — الإجمالي المخزّن ده باج مخزّن.
  • Reducers must be pure: no HTTP, no Date.now(), no random. All of that belongs in an effect, or devtools replay lies to you.الـ reducers لازم تكون نضيفة: مفيش HTTP ولا Date.now() ولا عشوائية. كل ده مكانه الـ effects، وإلا إعادة الـ devtools هتكدب عليك.
  • Not all state is global. Form drafts, open/closed panels and hover state belong in the component — putting them in a global store is pure overhead.مش كل حالة عامة. مسودات الفورمز والبانلز المفتوحة وحالة الـ hover مكانها الـ component — وحطها في store عام ده حِمل زيادة وبس.
  • Migrating from a plain signal service to SignalStore later is genuinely easy — the public shape is the same. That is a strong reason to start simple.التحويل من signal service عادية لـ SignalStore بعدين سهل فعلاً — الشكل العام واحد. وده سبب قوي إنك تبدأ بسيط.
