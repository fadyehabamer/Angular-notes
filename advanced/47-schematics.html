Custom schematics and buildersschematics و builders مخصصة

ng generate component is a schematic — a program that edits your project. You can write your own, so “create a feature” becomes one command instead of a page in a wiki that people follow differently. This is how a convention becomes enforceable instead of aspirational.ng generate component ده schematic — برنامج بيعدّل مشروعك. وتقدر تكتب بتاعك، فـ«اعمل فيتشر» تبقى أمر واحد بدل صفحة في wiki كل واحد بيطبقها بطريقة. وكده الـ convention بيبقى قابل للفرض بدل ما يبقى أمنية.

What it actually isهي إيه بالظبط

A schematic is your own ng generate — a script that writes files the way your team has agreed to write them.الـ schematic هو ng generate بتاعك إنت — سكريبت بيكتب ملفات بالطريقة اللي فريقك اتفق عليها.

Think of it likeاعتبرها زي

A rubber stamp for paperwork. Everyone's form comes out identical, and nobody has to remember the layout.ختم للورق. فورم كل واحد بيطلع زي التاني، ومحدش محتاج يفتكر الشكل.

You reach for it whenهتحتاجها لما

import { Rule, Tree, apply, url, template, move,         mergeWith, chain } from '@angular-devkit/schematics';import { strings } from '@angular-devkit/core'; export function feature(options: { name: string; path?: string }): Rule {  return chain([    // 1. write the files from templates    mergeWith(apply(url('./files'), [      template({        ...options,        ...strings,          // gives templates dasherize, classify, camelize      }),      move(options.path ?? `src/app/features/${strings.dasherize(options.name)}`),    ])),     // 2. edit an existing file    addRoute(options.name),  ]);} function addRoute(name: string): Rule {  return (tree: Tree) => {    const path = 'src/app/app.routes.ts';    const src = tree.read(path)?.toString('utf-8');    if (!src) return tree;     const route = `  { path: '${strings.dasherize(name)}', loadComponent: () =>\n` +      `      import('./features/${strings.dasherize(name)}/${strings.dasherize(name)}')\n` +      `        .then(m => m.${strings.classify(name)}) },\n`;     tree.overwrite(path, src.replace('routes: Routes = [', 'routes: Routes = [\n' + route));    return tree;  };}

Real exampleمثال حقيقي When a schematic pays for itselfإمتى الـ schematic يعوّض تكلفته

Writing one costs a day. It pays off when the same folder shape is created often and people keep getting it subtly wrong — because a schematic is a convention that cannot be forgotten, misread, or skipped when someone is in a hurry.كتابة واحد بتكلف يوم. وبيعوّض لما نفس شكل الفولدر يتعمل كتير والناس بتغلط فيه بشكل بسيط — لإن الـ schematic convention مستحيل يتنسي أو يتقرا غلط أو يتعدّى لما حد يكون مستعجل.

Watch outخد بالك

  • Test with --dry-run first. It prints every file it would create or change without touching disk.اختبر بـ --dry-run الأول. بيطبع كل ملف هيعمله أو يغيّره من غير ما يلمس الديسك.
  • Template files should end in .template so the TypeScript compiler does not try to build them as source.ملفات القوالب لازم تنتهي بـ .template عشان الـ TypeScript compiler ميحاولش يبنيها كمصدر.
  • Editing an existing file by string replacement is brittle. For anything beyond a simple insert, parse with the TypeScript AST instead of regex.تعديل ملف موجود باستبدال نصوص ده هش. وأي حاجة أكبر من إدخال بسيط، حلّلها بـ TypeScript AST مش بـ regex.
  • A schematic is a build-time tool, so it belongs in devDependencies. Shipping it as a runtime dependency bloats every install.الـ schematic أداة وقت build، فمكانه devDependencies. وشحنه كاعتمادية وقت تشغيل بيضخّم كل تثبيت.
  • Most teams need a schematic and never need a custom builder. If an npm script does the job, write the npm script.معظم الفرق محتاجة schematic ومش محتاجة builder مخصص أبداً. لو npm script بيعمل الشغل، اكتب الـ npm script.
If you remember one thingلو هتفتكر حاجة واحدة

Schematics also edit existing code, which is exactly how ng update migrates your app between versions.الـ schematics بتـعدّل كود موجود كمان، وده بالظبط إزاي ng update بينقل تطبيقك بين الإصدارات.

Q01 What is a schematic?إيه هو الـ schematic؟
whyليه

Every ng generate and every ng add is a schematic. Writing your own is how a team stops copying a folder by hand for the fortieth time.كل ng generate وكل ng add ده schematic. وإنك تكتب واحد من عندك هو إزاي الفريق يبطّل ينسخ فولدر بإيده للمرة الأربعين.

Q02 What does collection.json do?collection.json بيعمل إيه؟
whyليه

It is the index: ng g my-lib:feature looks up feature there and finds the factory to run, along with the schema describing its options.ده الفهرس: ng g my-lib:feature بيدوّر على feature هناك وبيلاقي المصنع اللي هيشتغل، ومعاه الـ schema اللي بتوصف خياراته.

Q03 Why are placeholders written as __name@dasherize__?ليه العناصر البديلة بتتكتب __name@dasherize__؟
whyليه

Both file names and file contents go through the template engine, so one stencil can produce user-profile.component.ts with a UserProfileComponent class inside it.أسماء الملفات ومحتواها الاتنين بيمروا من محرك القوالب، فقالب واحد يقدر يطلع user-profile.component.ts وجواه كلاس UserProfileComponent.

Q04 When is writing a schematic worth it?إمتى كتابة schematic تستاهل؟
whyليه

The value is consistency at scale: a feature folder that always has the same shape. For a one-off change, a small script or an editor snippet costs far less to write.القيمة هي الاتساق على نطاق واسع: فولدر ميزة بيبقى دايماً بنفس الشكل. أما لتغيير مرة واحدة، فسكربت صغير أو snippet في المحرر بيكلّف أقل بكتير.
