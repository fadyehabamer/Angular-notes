[class] and [style], name by name[class] و[style]، اسم اسم

The idea is simple: your data decides which CSS classes and styles an element gets. The confusing part is the names. One binding like [class.sold-out]="soldOut()" holds a word of the browser’s, a CSS class name your stylesheet must repeat, and a name from your component. And the word after the dot means something different for class than for style. This page untangles them.الفكرة بسيطة: الداتا بتاعتك هي اللي بتقرر العنصر ياخد أنهي CSS classes وأنهي styles. اللي بيلخبط هو الأسماء. binding واحد زي [class.sold-out]="soldOut()" جواه كلمة بتاعة المتصفح، واسم CSS class الـ stylesheet بتاعك لازم يكرره، واسم من الـ component بتاعك. والكلمة اللي بعد النقطة معناها مع class غير معناها مع style. الصفحة دي بتفك الربطة دي.

One product, five stopsمنتج واحد، خمس محطات

A shop badge. When a product is sold out, the badge fades. A thin bar under it shows how much stock is left. Follow a product from its data to its looks:بادج في محل. لما المنتج يخلص، البادج بيبهت. وتحته شريط رفيع بيوضح فاضل قد إيه في المخزن. امشي ورا منتج من الداتا بتاعته لحد شكله:

Every name you own has been swapped for a made-up word. Angular’s words did not move. This code still compiles and still works. That is the proof of which names are yours.كل اسم انت اللي اخترته اتبدّل بكلمة عشوائية. كلمات أنجولار فضلت مكانها. الكود ده لسه بيشتغل عادي. وده الدليل إن الأسماء دي بتاعتك.

  1. 1product.tsthe dataالداتا
    stock: number;turnip: number;

    Your data has a field stock. Every file that reads it types this exact name.الداتا بتاعتك فيها field اسمه stock. أي ملف بيقراه بيكتب الاسم ده بالظبط.

  2. 2badge.tsclass · decidesالكلاس · بيقرر
    readonly soldOut = computed(() => this.product().stock === 0);readonly donut = computed(() => this.waffle().turnip === 0);

    The class turns data into a yes/no. soldOut is a name you picked, used only by this component. computed is Angular’s.الكلاس بيحوّل الداتا لآه/لأ. وsoldOut اسم انت اخترته، والـ component ده بس اللي بيستخدمه. وcomputed بتاعة أنجولار.

  3. 3badge.htmltemplate · bindsالتمبلت · بيربط
    <span class="badge" [class.sold-out]="soldOut()"><span class="mango" [class.sold-banana]="donut()">

    Three owners in one binding. class is HTML’s attribute. sold-out is your CSS class name, which the stylesheet must repeat. soldOut in the quotes is your computed. When it is true, Angular adds the class; when false, it removes it.تلات أصحاب في binding واحد. class الـ attribute بتاع HTML. وsold-out اسم الـ CSS class بتاعك، والـ stylesheet لازم يكرره. وsoldOut اللي بين علامات التنصيص هو الـ computed بتاعك. لما يبقى صح أنجولار بيزوّد الـ class؛ ولما يبقى غلط بيشيلها.

  4. 4badge.cssstylesheet · stylesالـ stylesheet · بيدّي الشكل
    .sold-out { opacity: 0.5; }.sold-banana { opacity: 0.5; }

    The stylesheet spells sold-out again. This is the pair nobody checks: misspell one side and the badge simply never fades. opacity is a CSS property, the browser’s word.الـ stylesheet بيكتب sold-out تاني. ودي الجوز اللي محدش بيراجعه: اكتب ناحية غلط والبادج ببساطة عمره ما هيبهت. وopacity CSS property، كلمة المتصفح.

  5. 5badge.htmltemplate · sizesالتمبلت · بيحدد المقاس
    <div class="bar" [style.width.%]="stockLevel()"></div><div class="pickle" [style.width.%]="lemon()"></div>

    Now the dot means something else. After style comes width, a CSS property, not a name of yours. Then %, the unit. stockLevel is your number, with no unit in it.هنا النقطة معناها حاجة تانية. بعد style بييجي width، CSS property، مش اسم بتاعك. وبعدين %، الوحدة. وstockLevel الرقم بتاعك، من غير وحدة جواه.

The whole thing in one lineالحكاية كلها في سطر

In [class.sold-out]="soldOut()": class is HTML’s, sold-out is shared with your CSS file, soldOut is your component’s. In [style.width.%]="stockLevel()": style, width and % are fixed, and only stockLevel is yours.في [class.sold-out]="soldOut()": class بتاعة HTML، وsold-out متشاركة مع ملف الـ CSS بتاعك، وsoldOut بتاعة الـ component بتاعك. وفي [style.width.%]="stockLevel()": style وwidth و% ثابتين، وstockLevel بس اللي بتاعك.

Class, template or stylesheet?الكلاس ولا التمبلت ولا الـ stylesheet؟

Who writes what, and who picks the nameمين بيكتب إيه، ومين بيختار الاسم

Here the “other side” is not another component. It is your stylesheet. The template and the CSS file are the two files that must agree.هنا «الناحية التانية» مش component تاني. هي الـ stylesheet بتاعك. التمبلت وملف الـ CSS هما الملفين اللي لازم يتفقوا.

  • After class. comes your word. After style. comes the browser’s. [class.sold-out] names a CSS class you invented. [style.width] names a CSS property that already exists.بعد class. بتيجي كلمتك. وبعد style. بتيجي كلمة المتصفح. [class.sold-out] بتسمّي CSS class انت اخترعتها. و[style.width] بتسمّي CSS property موجودة أصلًا.
  • Inside the quotes is always your component. Whatever the left side is, the right side is an expression over your class: soldOut(), stockLevel(), product().name.اللي جوه علامات التنصيص دايمًا من الـ component بتاعك. مهما كانت الناحية الشمال، الناحية اليمين expression على الكلاس بتاعك: soldOut()، stockLevel()، product().name.
  • The stylesheet belongs to the component. styleUrl links badge.css to this component only. A .sold-out rule in some other component’s CSS will not reach the badge.الـ stylesheet تبع الـ component. styleUrl بتربط badge.css بالـ component ده بس. وقاعدة .sold-out في CSS بتاع component تاني مش هتوصل للبادج.

Mistakes that fail silently (and one that fails confusingly)غلطات بتفشل في صمت (وواحدة بتفشل بشكل ملخبط)

CSS forgives everything. An unknown class, an unknown property or a missing unit is not an error; it is simply ignored.الـ CSS بيسامح في كل حاجة. class مش معروفة، أو property مش معروفة، أو وحدة ناقصة، مش error؛ ببساطة بتتجاهل.

1The template and the stylesheet disagreeالتمبلت والـ stylesheet مش متفقين
