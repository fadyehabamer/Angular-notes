ngModel forms, name by nameفورمز ngModel، اسم اسم

The idea of a template-driven form is simple: you write normal inputs, add ngModel, and Angular builds the form object for you. The confusing part is the names. One input line can say email five times. Some are the browser’s, one is Angular’s validator, and the rest are yours, but you chose the same word for all of them. This page pulls them apart.فكرة الفورم اللي من التمبلت بسيطة: بتكتب inputs عادية، وتضيف ngModel، وأنجولار بيبني الفورم object بدالك. اللي بيلخبط هو الأسماء. سطر input واحد ممكن يقول email خمس مرات. شوية بتوع المتصفح، وواحدة الـ validator بتاع أنجولار، والباقي بتوعك، بس انت اخترت نفس الكلمة ليهم كلهم. الصفحة دي بتفكّهم عن بعض.

  1. 1contact.htmltemplate · the inputالتمبلت · الـ input

    The user types. Read the line left to right: name="email" is the control’s key (yours). type="email" is the browser’s. ngModel copies what is typed into model.email, your data field. The bare email is Angular’s validator. #email is a reference you named. Same word, five owners.المستخدم بيكتب. اقرا السطر من الشمال لليمين: name="email" مفتاح الـ control (بتاعك). type="email" بتاع المتصفح. ngModel بينسخ اللي بيتكتب في model.email، الـ field بتاع الداتا بتاعتك. وemail اللي لوحده ده الـ validator بتاع أنجولار. و#email reference انت سمّيته. نفس الكلمة، وخمس أصحاب.
