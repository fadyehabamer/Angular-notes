ng generate, name by nameng generate، اسم اسم

The idea is simple: you type one word, and the CLI writes the files for you. The confusing part is the names. From cart you suddenly have a folder, four files, a class called Cart and a tag called app-cart, and nobody told you which of those you may change, which ones other files depend on, and what the CLI did not do for you. This page answers exactly that.الفكرة بسيطة: بتكتب كلمة واحدة، والـ CLI بيكتبلك الملفات. اللي بيلخبط هو الأسماء. من كلمة cart فجأة بقى عندك فولدر، وأربع ملفات، وكلاس اسمه Cart، وتاج اسمه app-cart، ومحدش قالك مين فيهم ينفع تغيّره، ومين الملفات التانية معتمدة عليه، والـ CLI معملش إيه. الصفحة دي بتجاوب على ده بالظبط.

One word, five stopsكلمة واحدة، خمس محطات

You want a shopping cart on the home page. You type one command, make two small edits, and it is on screen. Follow the word cart:عايز سلة مشتريات في الصفحة الرئيسية. بتكتب أمر واحد، وتعمل تعديلين صغيرين، وتلاقيها على الشاشة. امشي ورا كلمة cart:

The whole thing in one lineالحكاية كلها في سطر

You type cart. The CLI makes cart/cart.ts, Cart and app-cart. You write import { Cart }, imports: [Cart] and <app-cart />. The CLI creates files; it never wires them.انت بتكتب cart. الـ CLI بيعمل cart/cart.ts وCart وapp-cart. وانت بتكتب import { Cart } وimports: [Cart] و<app-cart />. الـ CLI بيعمل الملفات؛ عمره ما بيوصّلها.

  • You type one word; the CLI makes four names from it. Folder and files cart, class Cart, selector app-cart. Type the word in lowercase with dashes: ng g c product-card gives product-card.ts, ProductCard and app-product-card.انت بتكتب كلمة؛ والـ CLI بيعمل منها أربع أسماء. فولدر وملفات cart، وكلاس Cart، وselector app-cart. اكتب الكلمة حروف صغيرة وبشَرط: ng g c product-card بتدّيك product-card.ts وProductCard وapp-product-card.

Every connection between two files is typed by you.الـ CLI بيعمل، وانت بتوصّل. عمره ما بيضيف الـ component بتاعك لـ imports حد، ولا بيكتب التاج، ولا بيضيف route. كل وصلة بين ملفين انت اللي بتكتبها.
  • In a command, only the end is yours. ng, new, generate, component, serve are the CLI’s words. After ng generate, the next five minutes are where beginners get stuck. Most of these give no error in the terminal.بعد ng generate، الخمس دقايق اللي بعدها هما اللي المبتدئين بيقفوا فيهم. أغلب دول مش بيدّوا أي error في الترمينال.

1routerLink without RouterLink in importsrouterLink من غير RouterLink في imports
src/app/app.tsavoidتجنّب
  imports: [RouterOutlet, Cart],  imports: [RouterOutlet, Avocado],
src/app/app.tsdo thisاعمل كده
  imports: [RouterOutlet, RouterLink, Cart],  imports: [RouterOutlet, RouterLink, Avocado],

Without RouterLink, routerLink="/about" is just an unknown HTML attribute on an <a> with no href. The browser ignores it. No error, and the link does nothing.من غير RouterLink، routerLink="/about" مجرد attribute مجهولة على <a> ملهاش href. المتصفح بيتجاهلها. لا error، واللينك مش بيعمل حاجة.

2href instead of routerLinkhref بدل routerLink
src/app/app.htmlavoidتجنّب
<a href="/about">About</a><a href="/sesame">About</a>
src/app/app.htmldo thisاعمل كده
<a routerLink="/about">About</a><a routerLink="/sesame">About</a>

The page does change, so it looks right. But href reloads the whole app from index.html, and everything in memory (the cart contents, a logged-in user) is gone.الصفحة بتتغير فعلًا، فشكلها صح. بس href بيعيد تحميل التطبيق كله من index.html، وكل حاجة في الذاكرة (محتويات السلة، اليوزر اللي عامل login) بتضيع.

3The link and the path disagreeاللينك والـ path مش زي بعض
src/app/app.htmlavoidتجنّب
<a routerLink="/about-us">About</a>
src/app/app.htmldo thisاعمل كده
<a routerLink="/about">About</a><a routerLink="/sesame">About</a>

URLs are plain strings, so nothing checks them at build time. Clicking goes nowhere, and only the browser console says Cannot match any routes. Copy the URL from app.routes.ts.الـ URLs مجرد نصوص، فمحدش بيتأكد منها وقت الـ build. الدوس مش بيودّي في حتة، والـ console بتاع المتصفح بس هو اللي بيقول Cannot match any routes. انسخ الـ URL من app.routes.ts.

4Generated, but never importedاتولّد، بس عمره ما اتعمله import
src/app/app.tsavoidتجنّب
  imports: [RouterOutlet, RouterLink],
src/app/app.tsdo thisاعمل كده
  imports: [RouterOutlet, RouterLink, Cart],  imports: [RouterOutlet, RouterLink, Avocado],

This one does give an error, but it confuses people: “'app-cart' is not a known element”. You generated it, so it must exist? It exists as a file. The parent still has to list it in imports.دي بتدي error، بس بيلخبط الناس: «'app-cart' is not a known element». انت ولّدته، يبقى أكيد موجود؟ موجود كملف. بس الأب لسه لازم يحطه في imports.

5Running ng generate outside the projectإنك تشغّل ng generate برّه المشروع
terminal · in your home folderavoidتجنّب
ng generate component cartng generate component avocado
terminal · inside the projectdo thisاعمل كده
cd my-shopcd my-potatong generate component cartng generate component avocado

The CLI needs angular.json to know where to put files and which prefix to use. Outside the project folder it refuses, with a message saying the command is not available outside a workspace.الـ CLI محتاج angular.json عشان يعرف يحط الملفات فين ويستخدم أنهي بادئة. برّه فولدر المشروع بيرفض، برسالة بتقول إن الأمر مش متاح برّه الـ workspace.

When the new thing does not showلما الحاجة الجديدة مش بتظهر

Six questions, in this orderست أسئلة، بالترتيب ده

You generated something and it is not on the screen. Ask these before anything else.ولّدت حاجة ومش ظاهرة على الشاشة. اسأل الأسئلة دي قبل أي حاجة.

Checkpointنقطة فحص

1. Did the CLI print CREATE lines, in the folder you expected?1. الـ CLI طبع سطور CREATE، في الفولدر اللي انت متوقعه؟

Checkpointنقطة فحص

2. Does the parent import the class and list it in imports: [ ]?2. الأب عامل import للكلاس وحاطه في imports: [ ]؟

Checkpointنقطة فحص

3. Is the tag spelled exactly like the selector string?3. التاج مكتوب بالظبط زي نص الـ selector؟

Checkpointنقطة فحص

4. For links: are RouterLink and RouterOutlet in imports?4. للينكات: RouterLink وRouterOutlet موجودين في imports؟

Checkpointنقطة فحص

5. Does every routerLink match a path (slash in the link, none in the path)?5. كل routerLink بيطابق path (بشَرطة في اللينك، ومن غيرها في الـ path)؟

Checkpointنقطة فحص

6. After renaming anything, does every path still point at a real file: templateUrl, styleUrl, each import?6. بعد ما غيّرت أي اسم، كل مسار لسه بيشاور على ملف حقيقي: templateUrl وstyleUrl وكل import؟
