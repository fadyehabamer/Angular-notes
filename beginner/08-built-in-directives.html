ngClass, ngStyle and friendsngClass و ngStyle وأخواتهم

Angular ships directives for the things every app needs. Two of them — ngClass and ngStyle — are so common that Angular built simpler replacements directly into the template syntax, and most modern code no longer imports them at all.أنجولار بييجي معاه directives للحاجات اللي كل تطبيق محتاجها. واتنين منهم — ngClass وngStyle — شائعين لدرجة إن أنجولار عمل بدائل أبسط جوه صياغة التمبلت نفسها، ومعظم الكود الحديث مبقاش بيعمل لهم import أصلاً.

What it actually isهي إيه بالظبط

ngClass and ngStyle let you turn CSS classes and styles on and off from your data.ngClass وngStyle بيخلوك تفتح وتقفل classes وستايلات من الداتا بتاعتك.

Think of it likeاعتبرها زي

A panel of light switches. Your data decides which switches are up and which are down.لوحة مفاتيح نور. الداتا بتاعتك هي اللي بتقرر أنهي مفتاح فاتح وأنهي طافي.

You reach for it whenهتحتاجها لما

Active tabs, invalid fields, sold-out badges — anything that changes appearance based on a condition.التاب المفتوح، والخانة الغلط، وعلامة (خلص من المخزن) — أي حاجة شكلها بيتغيّر حسب شرط.

The whole idea in 4 picturesالفكرة كلها في 4 صور

[class.x] toggles one[class.x] بتقلب واحد

Truthy adds the class, falsy removes it. Nothing else on the element is disturbed.لو صح بيضيف الـ class، ولو غلط بيشيله. ومش بيلخبط أي حاجة تانية في العنصر.

ngClass toggles manyngClass بتقلب كتير

Takes an object, an array or a string. The object form is the readable one.بتاخد object أو array أو string. صيغة الـ object هي أوضحهم.

[style.width.px][style.width.px]

The unit goes in the binding name, so you pass a plain number and never build strings.الوحدة بتتكتب في اسم الـ binding، فبتبعت رقم عادي ومش بتلزق نصوص.

Inline styles winالستايل المباشر بيكسب

ngStyle writes inline styles, which beat your stylesheet. Use it sparingly.ngStyle بيكتب inline styles، ودي بتغلب ملف الـ CSS بتاعك. استعملها بحساب.

Real exampleمثال حقيقي A status pill with four statesشارة حالة بأربع حالات

One computed decides the state; the template just binds it. Adding a fifth state later is one line in the class and zero changes to the template — which is the whole point of keeping logic out of the markup.computed واحدة بتقرر الحالة؛ والتمبلت بيربطها وخلاص. وإضافة حالة خامسة بعدين سطر واحد في الكلاس وصفر تغيير في التمبلت — وده كل الهدف من إنك تطلّع المنطق بره الماركب.

Watch outخد بالك

  • A class name with a dash needs quotes inside an object: { 'sold-out': true }. Without them it is a syntax error.اسم الـ class اللي فيه شرطة محتاج علامات تنصيص جوه الـ object: { 'sold-out': true }. ومن غيرها بيبقى syntax error.
  • [class] with a string replaces the bound classes each time. If you are building a string with +, an object is almost always clearer.[class] بنص بتستبدل الـ classes المربوطة كل مرة. ولو بتبني نص بـ +، الـ object تقريباً دايماً أوضح.
  • Setting a style to null removes it. Setting it to '' or undefined also works, but null is the explicit way to say “no value”.لما تحط استايل بـ null بيتشال. و'' أو undefined بيشتغلوا كمان، بس null هي الطريقة الصريحة اللي معناها «مفيش قيمة».
  • NgOptimizedImage requires width and height, and refuses to work without them. That is deliberate — it is what prevents layout shift.NgOptimizedImage محتاج width وheight، ومش بيشتغل من غيرهم. وده مقصود — هو اللي بيمنع الـ layout shift.
  • Forgetting NgClass in imports fails silently — the attribute is just ignored. This is a good reason to prefer [class], which cannot be forgotten.نسيان NgClass في imports بيفشل في صمت — الخاصية بتتجاهل وخلاص. وده سبب كويس إنك تفضّل [class]، اللي مستحيل تنساها.
If you remember one thingلو هتفتكر حاجة واحدة

For a single class, prefer [class.active]. Reach for ngClass only when several classes toggle together.لو class واحد، استعمل [class.active]. ماتلجأش لـ ngClass غير لما كذا class يتغيّروا مع بعض.
