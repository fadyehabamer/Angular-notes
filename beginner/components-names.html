@Component, name by name@Component، اسم اسم

The idea is simple: a component is a class with a label that says which tag it answers to. The confusing part is the names. One card has a class name, a selector, three file names, two inputs and a CSS class, and the parent types some of them again. Nobody tells you which ones the parent depends on, and why [name]="p.name" has the same word twice. This page answers exactly that.الفكرة بسيطة: الـ component كلاس عليه لافتة بتقول هو بيرد على أنهي تاج. اللي بيلخبط هو الأسماء. كارت واحد ليه اسم كلاس، وselector، وتلات أسماء ملفات، واتنين inputs، وCSS class، والأب بيكتب شوية منهم تاني. ومحدش بيقولك الأب معتمد على مين فيهم، وليه [name]="p.name" فيها نفس الكلمة مرتين. الصفحة دي بتجاوب على ده بالظبط.

One card, five stopsكارت واحد، خمس محطات

A page shows a list of people. Each person is drawn by a small reusable component, the user card. The card does not know where the people come from; the page tells it. Card or page?الكارت ولا الصفحة؟

Who writes what, and who picks the nameمين بيكتب إيه، ومين بيختار الاسم

  • The class name goes in TypeScript, the selector goes in HTML. UserCard appears only in .ts files (import, imports). app-user-card appears only as a tag in templates.   • Inside [ ] on the card’s tag, the name is the card’s. Inside the quotes, the names are the page’s. Every name on this page — yours or Angular’s?كل اسم في الصفحة دي — بتاعك ولا بتاع أنجولار؟

A component has three public faces: its class name (the parent lists it in imports), its selector (the parent types it as a tag) and its inputs (the parent sets them in [ ]). Those are orange. Everything green stays inside the component. Note the two name rows: the card’s input and the field in your data share a spelling, but they are different names.الـ component ليه تلات وشوش عمومية: اسم الكلاس (الأب بيحطه في imports)، والـ selector (الأب بيكتبه كتاج)، والـ inputs (الأب بيحطها في [ ]). دول البرتقاني. وكل حاجة خضرا بتفضل جوه الـ component. وخد بالك من صفين name: الـ input بتاع الكارت والـ field اللي في الداتا بتاعتك ليهم نفس الكتابة، بس هما اسمين مختلفين.
