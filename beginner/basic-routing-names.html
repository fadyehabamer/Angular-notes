Routing, name by nameالـ routing، اسم اسم

Routing has one idea: a URL picks a component, and the router draws it in a hole in your page. The confusing part is the names. The word products is typed in the route table, in every link and in every navigate(), sometimes with a slash and sometimes without. A :productId in a path must equal an input in another file. And almost none of it is checked by the compiler. This page shows which words are the router’s, which are yours, and which must match.الـ routing فيه فكرة واحدة: الـ URL بيختار component، والراوتر بيرسمه في فتحة في صفحتك. اللي بيلخبط هو الأسماء. كلمة products بتتكتب في جدول الـ routes، وفي كل لينك، وفي كل navigate()، مرة بشرطة ومرة من غير. و:productId في مسار لازم يساوي input في ملف تاني. وتقريبًا ولا حاجة من دول الـ compiler بيتأكد منها. الصفحة دي بتوريك أنهي كلمات بتاعة الراوتر، وأنهي بتاعتك، وأنهي لازم تطابق.

Both are yours, both are strings, and the compiler checks neither.اللينك: ['/products', p.id]. الـ route: 'products/:productId'. الصفحة: productId = input(). الكلمات اللي لازم تطابق هي products (اللينك والمسار) وproductId (المسار والـ input). الاتنين بتوعك، والاتنين نصوص، والـ compiler مش بيتأكد من ولا واحد فيهم.

  • The route table owns the URL words. Links and navigate() only repeat them. When in doubt, copy the word from app.routes.ts.جدول الـ routes هو صاحب كلمات الـ URL. اللينكات وnavigate() بيكرروها وبس. لو محتار، انسخ الكلمة من app.routes.ts.
  • A routed page is never written as a tag. You do not type <app-product-detail> anywhere. The router creates it inside <router-outlet>, and hands it values through inputs.الصفحة اللي بيجيبها الراوتر عمرها ما بتتكتب كتاج. انت مش بتكتب <app-product-detail> في أي حتة. الراوتر بيعملها جوه <router-outlet>، وبيديها القيم عن طريق الـ inputs.
  • Slash rule: paths in the table have no leading slash ('products'). Links usually start with one ('/products'), which means “from the root”. Same word, different slash.قاعدة الشرطة: المسارات في الجدول من غير شرطة في الأول ('products'). واللينكات غالبًا بتبدأ بواحدة ('/products')، ومعناها «من الأول خالص». نفس الكلمة، والشرطة مختلفة.

Every name on this page — yours or Angular’s?كل اسم في الصفحة دي — بتاعك ولا بتاع أنجولار؟

Most orange names on this page are strings: URL words, the param name, the CSS class. TypeScript does not read strings, so a mismatch is usually not a compile error. It shows up as the wrong page, an empty input, or a link that does nothing.أغلب الأسماء البرتقاني في الصفحة دي نصوص: كلمات الـ URL، واسم الـ param، والـ CSS class.
