The startup files, name by nameملفات التشغيل، اسم اسم

The idea is simple: the browser loads one almost-empty page, and Angular fills one tag in it. The confusing part is the names. The CLI wrote six files full of words like bootstrapApplication, appConfig, App and app-root, and nobody told you which ones you are allowed to touch, and which ones have to match another file. This page answers exactly that.الفكرة بسيطة: المتصفح بيحمّل صفحة واحدة شبه فاضية، وأنجولار بيملا تاج واحد فيها. اللي بيلخبط هو الأسماء. الـ CLI كتبلك ست ملفات مليانين كلمات زي bootstrapApplication وappConfig وApp وapp-root، ومحدش قالك مين فيهم مسموحلك تلمسه، ومين لازم يبقى زي حاجة في ملف تاني. الصفحة دي بتجاوب على ده بالظبط.

One page load, five stopsتحميل صفحة واحد، خمس محطات

You type localhost:4200 and press Enter. A second later your app is on the screen. In between, five files hand the job to each other, and each hand-over happens by name.   1. 1src/index.htmlthe browser · loadsالمتصفح · بيحمّل
    <body>  <app-root></app-root>  <app-banana></app-banana></body>

    The browser gets this page and shows… nothing. app-root is an empty tag with a name you chose. It is a placeholder: “the app goes here”. The build also slips a <script> tag in, and you never write that one.المتصفح بياخد الصفحة دي ويعرض… ولا حاجة. app-root تاج فاضي باسم انت اللي اخترته. ده مكان محجوز: «التطبيق هيتحط هنا». والـ build بيزوّد تاج <script> من عنده، وده عمرك ما بتكتبه.

  2. 2src/main.tsyour code · first lineكودك · أول سطر

    That script runs main.ts. bootstrapApplication is Angular’s.     Here appConfig is born. The name is yours; ApplicationConfig and providers are Angular’s and must be typed exactly.   4. 4src/app/app.tsfirst component · answersأول component · بيرد
    @Component({  selector: 'app-root',  selector: 'app-banana',  imports: [RouterOutlet],  templateUrl: './app.html',})export class App {export class Potato {  protected readonly title = signal('my-shop');  protected readonly pumpkin = signal('my-shop');}

    Angular now looks inside App and reads its selector: app-root. That string is the whole link back to index.html. Angular searches the page for that tag, and finds it.أنجولار دلوقتي بيبص جوه App ويقرا الـ selector بتاعه: app-root. النص ده هو الرابط الوحيد اللي بيرجّعك لـ index.html. أنجولار بيدوّر في الصفحة على التاج ده، ويلاقيه.

  5. 5src/app/app.htmlfirst component · drawsأول component · بيرسم
    <h1>{{ title() }}</h1><h1>{{ pumpkin() }}</h1> <router-outlet />

    The template is drawn inside <app-root>, and the page appears. title is the component’s own signal. router-outlet is Angular’s tag, and it only works because RouterOutlet is in imports.التمبلت بيترسم جوه <app-root>، والصفحة بتظهر. title الـ signal بتاعة الـ component نفسه. وrouter-outlet تاج أنجولار، وبيشتغل بس عشان RouterOutlet موجود في imports.

Everything else is Angular’s.index.html فيه <app-root>. وmain.ts بيقول bootstrapApplication(App, appConfig). وApp بيقول selector: 'app-root'. أربع أسماء بتوعك شايلين التشغيل كله: app-root وApp وappConfig وroutes. وكل حاجة تانية بتاعة أنجولار.

  • main.ts invents nothing. Every name in it is either Angular’s or imported from another file.
