Property, attribute, event and two-way bindingربط الـ property والـ attribute والحدث والاتجاهين

[x] sends data in, (x) sends events out, and [(x)] does both. Getting these four right — and knowing when a property is not an attribute — removes most of the "why is my binding not working" questions.[x] بتبعت داتا جوه، و(x) بتبعت أحداث بره، و[(x)] بتعمل الاتنين. وإتقان الأربعة دول — ومعرفة إمتى الـ property مش attribute — بيشيل معظم أسئلة «ليه الـ binding مش شغال».

What it actually isهي إيه بالظبط

Binding is a live wire between your class and your HTML, so you never touch the DOM with your own hands.الـ binding هو سلك حي بين الـ class والـ HTML، عشان متلمسش الـ DOM بإيدك أبداً.

Think of it likeاعتبرها زي

A thermostat taped to a thermometer. Change one and the other moves by itself. Nobody walks across the room to adjust anything.ترموستات ملزوق في ترمومتر. تغيّر واحد يتحرّك التاني لوحده. محدش بيقوم من مكانه يظبط حاجة.

You reach for it whenهتحتاجها لما

Every input box, every disabled button, every class that changes with state. Which is all day, every day.كل خانة إدخال، وكل زرار بيتقفل، وكل class بيتغيّر مع الحالة. يعني طول اليوم.

The whole idea in 4 picturesالفكرة كلها في 4 صور

[prop] goes down[prop] بتنزل

Class to DOM. Angular re-runs the expression whenever the value it reads changes.من الـ class للـ DOM. أنجولار بيعيد حساب التعبير كل ما القيمة تتغيّر.

(event) goes up(event) بتطلع

DOM to class. The browser fires, your method runs, state changes, the screen catches up.من الـ DOM للـ class. المتصفح بيطلق الحدث، الميثود بتشتغل، الحالة بتتغيّر، والشاشة بتلحق.

[( )] is both[( )] الاتنين

Banana in a box. [(ngModel)] is literally [ngModel] plus (ngModelChange).الموزة في الصندوق. [(ngModel)] حرفياً هي [ngModel] زائد (ngModelChange).

attr. for attributesattr. للـ attributes

Some things (colspan, aria-*) are HTML attributes, not DOM properties. Those need [attr.x].في حاجات زي colspan وaria-* دي attributes مش properties، فمحتاجة [attr.x].

Real exampleمثال حقيقي A search field, bound both ways by handخانة بحث، مربوطة في الاتجاهين بالإيد

Two-way binding on a native input is just a property binding plus an event binding written out. Seeing it explicitly once makes ngModel and model() stop feeling like magic.الـ two-way على input عادي هو مجرد property binding مع event binding مكتوبين بالطول. وشوفها صريحة مرة بيخلي ngModel و model() يبطلوا يحسوا إنهم سحر.

search.component.htmlexplicitصريح
<input  [value]="term()"  (input)="term.set($any($event.target).value)"  [attr.aria-label]="'Search ' + section()"  placeholder="Search…"> <button [disabled]="!canSubmit()" (click)="search()">Go</button> @if (term()) {  <button (click)="term.set('')" aria-label="Clear">×</button>} <p>{{ results().length }} results for “{{ term() }}”</p>
search.component.tsone signal drives it allsignal واحدة بتحرّك كله
export class Search {  readonly term = signal('');  readonly section = input('products');   readonly canSubmit = computed(() => this.term().trim().length > 1);  readonly results = computed(() => this.filter(this.term()));   // the input's value, the button's disabled state, the clear  // button's visibility and the result count all read one signal.}

Watch outخد بالك

  • Missing brackets. value="term()" puts the literal text term() in the box. If a binding shows your code on screen, this is why.الأقواس الناقصة. value="term()" بتحط النص الحرفي term() في الخانة. لو binding بيوريك كودك على الشاشة، ده السبب.
  • NG0303: Can’t bind to X means either the property does not exist (try [attr.X]) or the component that declares it is missing from imports.NG0303: Can’t bind to X معناها يا إن الـ property مش موجودة (جرّب [attr.X]) يا إن الـ component اللي بيعلنها ناقص من imports.
  • $event.target is typed as EventTarget, which has no .value. Use $any($event.target).value, or better, a template reference: #box then box.value.$event.target نوعها EventTarget، ومالهاش .value. استعمل $any($event.target).value، أو الأحسن، template reference: #box وبعدين box.value.
  • Two-way binding needs an exact name pair — x and xChange — or a single model(). Any other naming fails silently.الـ two-way محتاج زوج أسماء بالظبط — x وxChange — أو model() واحدة. وأي تسمية تانية بتفشل في صمت.
  • An event handler may do real work; a template expression may not. (click)="x = 5" is fine. {{ x = 5 }} is an error.معالج الحدث ينفع يعمل شغل حقيقي؛ أما تعبير التمبلت فلأ. (click)="x = 5" عادي. و{{ x = 5 }} ايرور.
If you remember one thingلو هتفتكر حاجة واحدة

Data flows down with [ ], events fly up with ( ), and [( )] is only ever both at once.الداتا بتنزل بـ [ ]، والأحداث بتطلع بـ ( )، و[( )] مش أكتر من الاتنين مع بعض.
