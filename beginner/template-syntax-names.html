Template syntax, name by nameصياغة التمبلت، اسم اسم

The idea is simple: a template is HTML that can read your class. {{ }} prints, [ ] sets, ( ) listens, # labels. The confusing part is the names. In one line like (click)="rename(box.value)" there are four words from three different owners, and nobody tells you which is which. This page answers exactly that.الفكرة بسيطة: التمبلت ده HTML بيقدر يقرا الكلاس بتاعك. {{ }} بتطبع، و[ ] بتحط، و( ) بتسمع، و# بتسمّي. اللي بيلخبط هو الأسماء. في سطر واحد زي (click)="rename(box.value)" فيه أربع كلمات من تلات أصحاب مختلفين، ومحدش بيقولك مين بتاع مين. الصفحة دي بتجاوب على ده بالظبط.

  1. 1profile.tsthe class · owns itالكلاس · صاحبها
    protected readonly name = signal('Mona');protected readonly muffin = signal('Mona');

    Everything the template shows starts in the class. name is yours; signal is Angular’s. protected means “the template may read this, other classes may not”.كل حاجة التمبلت بيعرضها بتبدأ في الكلاس. name بتاعك؛ وsignal بتاعة أنجولار. وprotected معناها «التمبلت يقدر يقرا ده، والكلاسات التانية لأ».

  2. 2profile.htmlthe template · printsالتمبلت · بيطبع
    <h1>{{ name() }}</h1><h1>{{ muffin() }}</h1>

    Inside {{ }}, Angular looks up name on the class. No this. in templates: every bare name means “my component’s”. The brackets read the signal.جوه {{ }}، أنجولار بيدوّر على name في الكلاس. مفيش this. في التمبلتس: أي اسم لوحده معناه «بتاع الـ component بتاعي». والقوسين بيقروا الـ signal.

  3. 3profile.htmlthe template · labelsالتمبلت · بيسمّي
    <input #box><input #carrot>

    The # gives this element a name, box. You picked it, and it exists only in this template. The class has no idea it exists.الـ # بتدّي العنصر ده اسم، box. انت اللي اخترته، وموجود في التمبلت ده بس. الكلاس ميعرفش إنه موجود أصلًا.

  4. 4profile.htmlthe template · listensالتمبلت · بيسمع
    <button (click)="rename(box.value)">Use what I typed</button><button (click)="pepper(carrot.value)">Use what I typed</button>

    Four words, three owners. click is the browser’s event. rename is your class’s method. box is the template’s label. value is the browser’s property of an input.أربع كلمات، تلات أصحاب. click الـ event بتاع المتصفح. وrename الميثود بتاعة الكلاس بتاعك. وbox الاسم اللي التمبلت ادّاه. وvalue الـ property بتاعة الـ input في المتصفح.

  5. 5profile.tsthe class · updatesالكلاس · بيحدّث
    protected rename(newName: string) {protected pepper(lemon: string) {  this.name.set(newName.trim());  this.muffin.set(lemon.trim());}

    Back in the class, the value arrives as a parameter. You can call it anything; here it is newName. set changes the signal, and the <h1> updates by itself.ورجعنا للكلاس، القيمة بتوصل كـ parameter. تقدر تسمّيه أي حاجة؛ هنا اسمه newName. وset بتغيّر الـ signal، والـ <h1> بيتحدّث لوحده.

The whole thing in one lineالحكاية كلها في سطر

In a template, a bare name is yours: first the template’s own names (#box, @let, loop variables), then your class’s members. After a dot on an element, or inside [ ] and ( ) on a plain HTML tag, the name is the browser’s. A name starting with $ or @ is Angular’s.في التمبلت، الاسم اللي لوحده بتاعك: الأول أسماء التمبلت نفسه (#box و@let ومتغيرات اللوب)، وبعدين members الكلاس بتاعك. وبعد نقطة على عنصر، أو جوه [ ] و( ) على تاج HTML عادي، الاسم بتاع المتصفح. وأي اسم بيبدأ بـ $ أو @ بتاع أنجولار.
