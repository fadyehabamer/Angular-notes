Template syntax and interpolationصياغة التمبلت والـ interpolation

An Angular template is HTML with four extra powers. {{ }} prints a value, [ ] sets a property, ( ) listens for an event, and #name labels an element. Everything else you will ever write in a template is one of those four.تمبلت أنجولار ده HTML بأربع قدرات زيادة. {{ }} بتطبع قيمة، و[ ] بتحط property، و( ) بتسمع لحدث، و#name بتسمّي عنصر. وأي حاجة تانية هتكتبها في تمبلت هي واحدة من الأربعة دول.

What it actually isهي إيه بالظبط

Template syntax is the small set of extra symbols you write inside HTML so Angular knows which bits to fill in.الـ template syntax هي شوية رموز زيادة بتكتبها جوه الـ HTML عشان أنجولار يعرف الحتت اللي هيملاها.

Think of it likeاعتبرها زي

Mail merge in a word processor. You write Dear {{name}} once, and the printer swaps in a real name on every letter.زي الـ mail merge في الوورد. بتكتب عزيزي {{name}} مرة واحدة، والطابعة بتحط اسم حقيقي في كل جواب.

Watch outخد بالك

  • {{ }} outputs text, always. To render HTML you need [innerHTML], which Angular sanitizes — and which you should be nervous about.{{ }} بتطلّع نص، دايماً. وعشان ترندر HTML محتاج [innerHTML]، واللي أنجولار بيعقّمه — واللي المفروض تبقى قلقان منه.
  • Calling a method in a template runs it on every change detection pass. Use a computed() or a pipe instead.إنك تنادي method في تمبلت بيشغّلها في كل دورة change detection. استعمل computed() أو pipe بدل كده.
  • Signals need parentheses: {{ name() }}. {{ name }} prints the function source and @if (name) is always true.الـ signals محتاجة قوسين: {{ name() }}. أما {{ name }} فبتطبع كود الدالة، و@if (name) بتبقى true دايماً.
  • Template expressions cannot see globals. If you need Math.max or window, expose it as a class field or a computed.تعبيرات التمبلت مش شايفة الـ globals. لو محتاج Math.max أو window، اعرضهم كحقل في الكلاس أو computed.
  • @let cannot be reassigned and is only visible after its declaration, inside the same block. It is a name, not a variable.@let مينفعش تتغير وبتبقى ظاهرة بس بعد تعريفها، وجوه نفس البلوك. هي اسم، مش متغير.

Q01 What does {{ }} do?{{ }} بتعمل إيه؟
whyليه

Interpolation is read-only and one-way: expression in, text out. It also escapes what it writes, which is why {{ userInput }} can never inject HTML — a fact worth remembering when you are tempted by [innerHTML].الإدراج للقراءة بس وفي اتجاه واحد: تعبير داخل، نص خارج. وكمان بيأمّن اللي بيكتبه، وعلشان كده {{ userInput }} مستحيل يحقن HTML — وهي حقيقة تستحق التذكر لما تتحمس لـ [innerHTML].

Q02 Which of these is not allowed in a template expression?أنهي واحدة من دول مش مسموحة في تعبير template؟
whyليه

Templates allow expressions, not statements — no assignment, no ++, no new. The restriction is deliberate: rendering must not change state, or the next render would read something different and you would get an infinite loop.الـ templates بتسمح بتعبيرات، مش أوامر — مفيش إسناد ولا ++ ولا new. والقيد ده مقصود: الرسم مينفعش يغيّر الحالة، وإلا الرسم اللي بعده هيقرا حاجة مختلفة وتدخل في لفة لا نهائية.

Q03 What is #box in <input #box>?إيه #box في <input #box>؟
whyليه

#box names the element so the rest of the template can use it: box.value, box.focus(). Put it on a component tag instead and you get that component's instance, which is how a parent calls a child's method.#box بتسمّي العنصر علشان باقي الـ template يستخدمه: box.value وbox.focus(). ولو حطّيتها على تاج component بتاخد نسخة الـ component، وده إزاي الأب بينادي دالة في الابن.

Q04 Why does the template render before your HTTP data arrives?ليه الـ template بيترسم قبل ما بيانات الـ HTTP توصل؟
whyليه

Angular draws once, immediately, with whatever the fields hold — usually nothing. That is why {{ user.name }} throws while {{ user?.name }} does not. Better still, guard the block with @if (user()) and give the field a safe default.أنجولار بيرسم مرة واحدة، فوراً، بأي حاجة المتغيّرات شايلاها — وغالباً مفيش حاجة. وعلشان كده {{ user.name }} بترمي خطأ و{{ user?.name }} لأ. والأحسن إنك تحمي البلوك بـ @if (user()) وتدّي المتغيّر قيمة ابتدائية آمنة.
