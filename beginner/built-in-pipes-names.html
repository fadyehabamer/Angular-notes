Pipes, name by nameالـ pipes، اسم اسم

The idea is simple: a pipe changes how a value looks on screen, never the value itself. The confusing part is the names. Every pipe has two of them (DatePipe in your imports, date in your template), the arguments are Angular’s vocabulary where one capital letter changes the meaning, and async invents a new name for you with as. This page sorts out which is which.الفكرة بسيطة: الـ pipe بتغيّر شكل القيمة على الشاشة، عمرها ما بتغيّر القيمة نفسها. اللي بيلخبط هو الأسماء. كل pipe ليها اسمين (DatePipe في الـ imports، وdate في التمبلت)، والـ arguments مفردات أنجولار وحرف كابيتال واحد بيغيّر المعنى، وasync بتألّفلك اسم جديد بـ as. الصفحة دي بترتّب مين إيه.

One order, five stopsأوردر واحد، خمس محطات

An order page. The component asks the server for order 1042. The answer arrives later, as raw data: a date as ISO text, a total as a plain number, a discount as a fraction. Pipes turn those into something a person can read. Follow the order:صفحة أوردر. الـ component بيطلب من السيرفر أوردر 1042. الرد بيوصل بعدين، كداتا خام: تاريخ كنص ISO، وإجمالي كرقم عادي، وخصم ككسر. والـ pipes بتحوّلهم لحاجة الإنسان يقدر يقراها. امشي ورا الأوردر:

  1. 1order-view.tsclass · asksالكلاس · بيطلب
    readonly order$ = this.http.get<Order>('/api/orders/1042');readonly muffin$ = this.kiwi.get<Banana>('/api/orders/1042');

    get is Angular’s and returns an observable: a value that will arrive later. order$ is your name for it; the $ is only a habit. Order is your type.get بتاعة أنجولار وبترجّع observable: قيمة هتوصل بعدين. وorder$ الاسم بتاعك ليها؛ والـ $ مجرد عادة. وOrder الـ type بتاعك.

  2. 2order-view.htmltemplate · waitsالتمبلت · بيستنى
    @if (order$ | async; as order) {@if (muffin$ | async; as taco) {

    async is Angular’s: it subscribes and hands over the value when it comes. as is Angular’s too. order is a new name you invent here for the arrived value. It lives only inside this block.async بتاعة أنجولار: بتعمل subscribe وبتسلّم القيمة أول ما توصل. وas بتاعة أنجولار برضه. وorder اسم جديد انت بتألفه هنا للقيمة اللي وصلت. عايش جوه البلوك ده بس.

  3. 3order-view.htmltemplate · formatsالتمبلت · بينسّق
    <p>Placed {{ order.placedAt | date:'dd/MM/yyyy' }}</p><p>Placed {{ taco.mango | date:'dd/MM/yyyy' }}</p>

    Left of the bar is yours: order and your field placedAt. Right of the bar is Angular’s: the pipe name date. After the colon comes an argument in Angular’s own little language, dd/MM/yyyy, where capitals matter.شمال الشرطة بتاعك: order والـ field بتاعك placedAt. ويمين الشرطة بتاع أنجولار: اسم الـ pipe date. وبعد النقطتين بييجي argument بلغة أنجولار الصغيرة، dd/MM/yyyy، والحروف الكابيتال فيها فارقة.

  4. 4order-view.tsclass · importsالكلاس · بيعمل import
    imports: [AsyncPipe, DatePipe, CurrencyPipe, PercentPipe],

    The same pipes under their other names. DatePipe is the class you import; date is what the template types. Both are Angular’s. Forget one here and the template does not compile.نفس الـ pipes بأساميهم التانية. DatePipe الكلاس اللي بتعمله import؛ وdate اللي التمبلت بيكتبه. الاتنين بتوع أنجولار. انسى واحدة هنا والتمبلت مش هيعمل compile.

  5. 5app.config.tsapp · picks the languageالتطبيق · بيختار اللغة
    { provide: LOCALE_ID, useValue: 'ar-EG' },

    Not a single name of yours. LOCALE_ID is Angular’s token and ar-EG is a world-standard locale id. This one line decides how every date and currency in the app looks.ولا اسم واحد بتاعك. LOCALE_ID الـ token بتاع أنجولار، وar-EG id عالمي للـ locale. السطر ده لوحده بيقرر شكل كل date وcurrency في التطبيق.

Your part stops at the |.في {{ order.placedAt | date:'dd/MM/yyyy' }}: order بتاعك، وplacedAt من الداتا بتاعتك، وdate بتاعة أنجولار، و'dd/MM/yyyy' مكتوبة بلغة التواريخ بتاعة أنجولار. الجزء بتاعك بيخلص عند الـ |.

  • Left of | is yours, right of it is Angular’s. The value and its fields come from your code. The pipe name and its arguments come from Angular.شمال الـ | بتاعك، ويمينها بتاع أنجولار. القيمة والـ fields بتاعتها جايين من الكود بتاعك. واسم الـ pipe والـ arguments بتوعها جايين من أنجولار.
  • Arguments go in a fixed order, after colons. currency:'EGP':'symbol':'1.0-0' means code, then display, then digits.
