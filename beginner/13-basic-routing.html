Routing and navigation, the basicsالـ routing والتنقل، الأساسيات

Your app has one HTML file, so a "page" is a component the router swaps into a hole in your layout. Three things do all of it: a routes array, a <router-outlet />, and routerLink on your links.تطبيقك فيه ملف HTML واحد، فالـ «صفحة» دي component الراوتر بيبدّله في فتحة في التخطيط بتاعك. وتلات حاجات بيعملوا ده كله: مصفوفة routes، و<router-outlet />، وrouterLink على اللينكات.

What it actually isهي إيه بالظبط

The router swaps components in and out of a hole in your page whenever the URL changes.الراوتر بيبدّل الـ components جوه فتحة في صفحتك كل ما الـ URL يتغيّر.

Think of it likeاعتبرها زي

A picture frame with a stack of photos behind it. Changing the URL slides a different photo into the same frame — the frame never moves.برواز وراه كومة صور. لما تغيّر الـ URL، صورة تانية بتدخل في نفس البرواز — والبرواز نفسه مابيتحركش.

You reach for it whenهتحتاجها لما

As soon as your app has more than one screen. Which is basically immediately.أول ما يبقى في تطبيقك أكتر من شاشة. يعني فوراً تقريباً.

The whole idea in 4 picturesالفكرة كلها في 4 صور

routes is just an arrayroutes مجرد array

A list of { path, component } objects. Plain data you can log and read.لستة من { path, component }. داتا عادية تقدر تطبعها وتقراها.

routerLink changes the URLrouterLink بتغيّر الـ URL

On an anchor tag. The browser does not reload; the router just notices.على تاج anchor. المتصفح مابيعملش reload؛ الراوتر بس بياخد باله.

router-outlet is the holerouter-outlet هي الفتحة

Whatever route matched gets rendered exactly here. Everything around it stays put.الـ route اللي طابق بيترسم هنا بالظبط. وكل اللي حواليه بيفضل مكانه.

** must be last** لازم تكون آخر واحدة

The wildcard route matches everything, so anything after it is unreachable.الـ wildcard بتطابق أي حاجة، فأي حاجة بعدها مش هتتنادى أبداً.

app.routes.tsthe mapالخريطة
import { Routes } from '@angular/router'; export const routes: Routes = [  // '' is the home page. pathMatch: 'full' or it matches everything.  { path: '', pathMatch: 'full', redirectTo: 'products' },   {    path: 'products',    title: 'Products',        // sets the browser tab title. free a11y win.    loadComponent: () => import('./pages/products').then(m => m.Products),  },   // :id is a PARAMETER — /products/42 puts '42' into it  {    path: 'products/:id',    loadComponent: () => import('./pages/product-detail').then(m => m.ProductDetail),  },   { path: 'about', loadComponent: () => import('./pages/about').then(m => m.About) },   // ** matches anything left over. it MUST be last.  { path: '**', loadComponent: () => import('./pages/not-found').then(m => m.NotFound) },];

Watch outخد بالك

  • Use routerLink, never href, for links inside your app. href triggers a full page reload and throws away all your state.استعمل routerLink مش href للينكات جوه تطبيقك. href بيعمل إعادة تحميل كاملة وبيرمي كل حالتك.
  • RouterOutlet, RouterLink and RouterLinkActive must be in imports. A missing RouterLink makes the anchor do nothing at all — silently.RouterOutlet وRouterLink وRouterLinkActive لازم يكونوا في imports. ولو RouterLink ناقص اللينك مش هيعمل حاجة خالص — وفي صمت.
  • path: '' without pathMatch: 'full' matches every URL, so nothing below it is ever reached.path: '' من غير pathMatch: 'full' بتطابق كل URL، فمفيش حاجة تحتها بتتوصل أبداً.
  • Paths have no leading slash in the routes array ('about'), but links do (routerLink="/about"). Mixing them up is a very common first-day bug.المسارات مفيهاش شرطة في الأول في مصفوفة الـ routes ('about')، لكن اللينكات فيها (routerLink="/about"). وخلطهم باج شائع جداً أول يوم.
  • routerLinkActive matches by prefix. Add [routerLinkActiveOptions]="{ exact: true }" to your home link or it stays highlighted everywhere.routerLinkActive بتطابق بالبادئة. ضيف [routerLinkActiveOptions]="{ exact: true }" للينك الرئيسية وإلا هتفضل منوّرة في كل حتة.
If you remember one thingلو هتفتكر حاجة واحدة

routerLink changes the page without reloading. href reloads everything and wipes every signal you had.routerLink بتغيّر الصفحة من غير reload. وhref بتعيد تحميل كل حاجة وبتمسح كل signal كان عندك.
