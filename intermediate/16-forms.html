Typed forms, and the null that surprises everyoneفورمز بأنواع حقيقية، والـ null اللي بتفاجئ الكل

Reactive forms carry real types now. The catch: a control resets to null unless you say otherwise, so your string is quietly a string | null — and that is where the flood of ?. and ! in form code comes from.الـ reactive forms بقى ليها أنواع حقيقية. المشكلة: الـ control بيرجع لـ null إلا لو قلت له لأ، فالـ string بتاعك في الحقيقة string | null — ومن هنا بييجي طوفان الـ ?. والـ ! في كود الفورمز.

What it actually isهي إيه بالظبط

Reactive forms mean you build the form in TypeScript first, then point the HTML at it — instead of the other way round.الـ reactive forms معناها إنك تبني الفورم في TypeScript الأول، وبعدين توجّه الـ HTML عليه — مش العكس.

Think of it likeاعتبرها زي

A spreadsheet next to a paper form. The spreadsheet is the real thing; the paper is just a view of it that you can hand to someone.شيت إكسيل جنب ورقة فورم. الشيت هو الحقيقة، والورقة مجرد عرض ليه تقدر تدّيه لحد.

You reach for it whenهتحتاجها لما

Anything with dynamic fields, cross-field rules, or a test you actually want to write.أي حاجة فيها خانات ديناميكية، أو قواعد بين الخانات، أو اختبار عايز تكتبه فعلاً.

The whole idea in 4 picturesالفكرة كلها في 4 صور

FormGroup is an objectFormGroup عبارة عن object

A named bag of controls. Nested groups mirror nested data exactly.شنطة فيها خانات بأسماء. الـ groups المتداخلة بتطابق الداتا المتداخلة بالظبط.

formControlName connectsformControlName بتوصّل

The HTML never owns the value; it only points at a control that already exists.الـ HTML عمره ما بيملك القيمة؛ هو بس بيشاور على خانة موجودة أصلاً.

Validators are functionsالفاليديتورز دوال

A function in, an error object or null out. You can write your own in four lines.دالة داخلة، وobject فيه الغلط أو null خارج. تقدر تكتب واحدة في أربع سطور.

Cross-field rules go on the groupقواعد الخانات على الـ group

Password vs confirm-password is a group validator, never a control validator.مقارنة الباسورد بتأكيدها validator على الـ group، مش على الخانة.

Real exampleمثال حقيقي An address form that changes shape by countryفورم عنوان بيتغير شكله حسب البلد

Picking Egypt shows a governorate field and hides the postcode; picking Germany does the reverse. Validators are added and removed at runtime, and updateValueAndValidity is the line everybody forgets.لما تختار مصر بيظهر حقل المحافظة ويختفي الرقم البريدي؛ ولما تختار ألمانيا بيحصل العكس. الفاليديتورز بتتضاف وتتشال وقت التشغيل، وسطر updateValueAndValidity هو اللي الكل بينساه.

address-form.component.tsdynamic rulesقواعد متغيرة
export class AddressForm {  readonly form = this.fb.nonNullable.group({    country:     ['EG'],    street:      ['', Validators.required],    governorate: [''],    postcode:    [''],  });   constructor() {    this.form.controls.country.valueChanges      .pipe(takeUntilDestroyed())      .subscribe(c => this.applyCountryRules(c));  }   private applyCountryRules(country: string) {    const gov = this.form.controls.governorate;    const post = this.form.controls.postcode;     gov.setValidators(country === 'EG' ? [Validators.required] : []);    post.setValidators(country === 'EG' ? [] : [Validators.required]);     // without these two lines the form keeps the OLD validity    gov.updateValueAndValidity();    post.updateValueAndValidity();  }}

Watch outخد بالك

  • form.value excludes disabled controls and is therefore a Partial. Use getRawValue() when you submit.form.value بيستبعد الـ controls المعطلة وعشان كده نوعها Partial. استعمل getRawValue() وقت الإرسال.
  • setValidators() does not re-run validation. Follow it with updateValueAndValidity() or the form keeps its old verdict.setValidators() مبيعيدش التحقق. لازم تتبعه بـ updateValueAndValidity() وإلا الفورم هيفضل على حكمه القديم.
  • Subscribing to valueChanges without takeUntilDestroyed() is a real leak — unlike HTTP, this stream never completes.الـ subscribe لـ valueChanges من غير takeUntilDestroyed() ده تسريب حقيقي — عكس الـ HTTP، الستريم ده عمره ما بيقفل.
  • disabled: true inside the control config is a known trap in reactive forms. Set it with control.disable() instead.disabled: true جوه إعداد الـ control فخ معروف في الـ reactive forms. استعمل control.disable() بدالها.
  • “Invalid input” tells nobody anything. Say what is wrong and what fixes it: Password needs at least 8 characters.“Invalid input” مش بتقول لحد أي حاجة. قول إيه الغلط وإيه اللي يصلّحه: الباسورد لازم 8 حروف على الأقل.
If you remember one thingلو هتفتكر حاجة واحدة

Use nonNullable or your reset() quietly turns every value into null and every type into a lie.استعمل nonNullable وإلا الـ reset() هتحوّل كل القيم لـ null من غير ما تحس، وكل الأنواع تبقى كدب.

Q01 A validator compares two fields. Where does it go?مُحقّق بيقارن خانتين. بيتحط فين؟
whyليه

A control validator only ever receives its own value. Cross-field rules — password confirmation, end-after-start — belong on the group, where both values are in hand.مُحقّق الخانة بياخد قيمته هو بس. أما القواعد اللي بين الخانات — زي تأكيد كلمة السر أو تاريخ نهاية بعد البداية — فمكانها على الـ group، حيث القيمتين في إيدك.

Q02 form.value is missing a field you know exists. Why?form.value ناقص خانة إنت متأكد إنها موجودة. ليه؟
whyليه

value deliberately omits disabled controls, on the grounds that the user could not edit them. getRawValue() returns everything. This bites hardest when a disabled id silently stops reaching your API.value بتستبعد الخانات المعطّلة بشكل مقصود، على أساس إن المستخدم مقدرش يعدّلها. وgetRawValue() بترجّع كل حاجة. والمشكلة دي بتوجع أكتر لما id معطّل يبطّل يوصل للـ API بهدوء.

Q03 setValue versus patchValue?setValue مقابل patchValue؟
whyليه

setValue is strict and will throw if a key is missing — useful when you want that safety. patchValue is forgiving, which makes it right for filling part of a form from a server response.setValue صارمة وبترمي خطأ لو مفتاح ناقص — وده مفيد لما تعوز الأمان ده. وpatchValue متسامحة، وعلشان كده هي الصح لما تملا جزء من فورم من رد السيرفر.

Q04 Which module do reactive forms need?الـ reactive forms محتاجة أنهي module؟
whyليه

ReactiveFormsModule brings formGroup, formControlName and formArrayName. FormsModule is the template-driven one, with ngModel — importing the wrong one produces a puzzling can't bind to error.ReactiveFormsModule بتجيب formGroup وformControlName وformArrayName. وFormsModule هي بتاعة الـ template مع ngModel — ولو عملت import للغلط هتطلعلك رسالة can't bind to محيّرة.
