Reactive forms, name by nameالـ reactive forms، اسم اسم

The idea of reactive forms is simple: you build the form in TypeScript, then point the HTML at it. The confusing part is the names. The word email is a key in group({ … }), a string in formControlName, a property in controls.email, and also Angular’s Validators.email and its error key. Some of these are checked by the compiler, some only at runtime, some never. This page shows which is which.فكرة الـ reactive forms بسيطة: بتبني الفورم في TypeScript، وبعدين توجّه الـ HTML عليه. اللي بيلخبط هو الأسماء. كلمة email مفتاح في group({ … })، ونص في formControlName، وproperty في controls.email، وكمان Validators.email بتاعة أنجولار ومفتاح الـ error بتاعها. شوية منهم الـ compiler بيتأكد منهم، وشوية وقت التشغيل بس، وشوية عمره ما حد بيتأكد. الصفحة دي بتوريك مين فيهم إيه.

The whole thing in one lineالحكاية كلها في سطر

You name a control once, in group({ email: … }). Then you repeat that exact word in formControlName="email", controls.email, raw.email, and any string like 'password'. Every other email on the page belongs to Angular or the browser.بتسمّي الـ control مرة واحدة، في group({ email: … }). وبعدين بتكرر نفس الكلمة بالظبط في formControlName="email"، وcontrols.email، وraw.email، وأي نص زي 'password'. وأي email تانية في الصفحة بتاعة أنجولار أو المتصفح.

Most of these come from a name typed twice, once in a checked place and once in an unchecked one.أغلب دول جايين من اسم متكتب مرتين، مرة في مكان بيتأكد منه ومرة في مكان مش بيتأكد منه.

1A typo in formControlNameغلطة إملائية في formControlName
signup.htmlavoidتجنّب
<input formControlName="emial" type="email">
signup.htmldo thisاعمل كده
<input formControlName="email" type="email"><input formControlName="banana" type="email">

It builds fine. When the page opens, Angular throws “Cannot find control with name: ‘emial’”. The message is accurate; just copy the key from the group.بيعمل build عادي. ولما الصفحة تفتح، أنجولار بيرمي «Cannot find control with name: ‘emial’». الرسالة مظبوطة؛ انسخ المفتاح من الـ group وخلاص.

2A validator string that is not a control nameنص في الـ validator مش اسم control
signup.tsavoidتجنّب
}, { validators: matchFields('password', 'confirmPassword') });}, { validators: waffle('potato', 'confirmPassword') });
signup.tsdo thisاعمل كده
}, { validators: matchFields('password', 'confirm') });}, { validators: waffle('potato', 'mango') });

The group has no confirmPassword, so get() returns null and its value is undefined. A real password never equals undefined, so “do not match” shows forever and the form can never be sent. No error anywhere.الـ group مفيهوش confirmPassword، فـ get() بترجّع null وقيمتها undefined. وأي باسورد حقيقي عمره ما يساوي undefined، فـ«مش متطابقين» بتفضل ظاهرة على طول والفورم عمره ما هيتبعت. ومفيش error في أي حتة.

3The function name used as the error keyاسم الـ function مستخدم كمفتاح error
signup.htmlavoidتجنّب
@if (passCtrl.errors?.['minLength']; as tooShort) { … }@if (biscuit.errors?.['minLength']; as cookie) { … }
signup.htmldo thisاعمل كده
@if (passCtrl.errors?.['minlength']; as tooShort) { … }@if (biscuit.errors?.['minlength']; as cookie) { … }

You call Validators.minLength, but the key it sets is minlength. The capital-L key never exists, so the message never shows, and errors accepts any string without complaint.انت بتنادي Validators.minLength، بس المفتاح اللي بتحطه minlength. والمفتاح اللي بـ L كابيتال عمره ما بيبقى موجود، فالرسالة عمرها ما بتظهر، وerrors بيقبل أي نص من غير ما يشتكي.

4Reading a group error on a controlقراية error الـ group من على control
signup.htmlavoidتجنّب
@if (form.controls.confirm.errors?.['mismatch']) { … }@if (taco.controls.mango.errors?.['pickle']) { … }
signup.htmldo thisاعمل كده
@if (form.errors?.['mismatch']) { … }@if (taco.errors?.['pickle']) { … }

The validator is attached to the group, so its key lands on form.errors. The confirm control only has its own errors, like required. Right key, wrong place: silence.الـ validator متعلّق على الـ group، فالمفتاح بتاعه بيقع في form.errors. والـ control confirm فيه الأخطاء بتاعته هو بس، زي required. المفتاح صح، والمكان غلط: سكوت.

5Forgetting nonNullableنسيان nonNullable
signup.ts · no nonNullableavoidتجنّب
readonly form = this.fb.group({readonly taco = this.kiwi.group({  email: ['', Validators.required],  banana: ['', Validators.required],});// raw.email is string | null
signup.ts · with nonNullabledo thisاعمل كده
readonly form = this.fb.nonNullable.group({readonly taco = this.kiwi.nonNullable.group({  email: ['', Validators.required],  banana: ['', Validators.required],});// raw.email is string

Without it, each control can be reset to null, so its type is string | null. Then signUp(raw.email, …) fails with “string | null is not assignable to string”, an error that never mentions forms. The name email is fine; the missing word is nonNullable.من غيرها، كل control ممكن يرجع لـ null في الـ reset، فنوعه بيبقى string | null. وساعتها signUp(raw.email, …) بتفشل بـ «string | null is not assignable to string»، error عمره ما بيجيب سيرة الفورمز. الاسم email تمام؛ الكلمة الناقصة هي nonNullable.

When it does nothingلما مايعملش حاجة

Six questions, in this orderست أسئلة، بالترتيب ده

Your form “does not work”: an input is not connected, an error never shows, or the button never enables. Ask these first.الفورم بتاعك «مش شغال»: input مش متوصّل، أو error عمره ما بيظهر، أو الزرار عمره ما بيتفعّل. اسأل دول الأول.

Checkpointنقطة فحص

1. Is ReactiveFormsModule in imports? Without it you get “Can’t bind to ‘formGroup’ since it isn’t a known property of ‘form’”.1. ReactiveFormsModule موجود في imports؟ من غيره هتاخد «Can’t bind to ‘formGroup’ since it isn’t a known property of ‘form’».

Checkpointنقطة فحص

2. Does every formControlName value exactly match a key in group({ … })?2. كل قيمة formControlName مطابقة بالظبط لمفتاح في group({ … })؟

Checkpointنقطة فحص

3. Do the strings you pass to your own validators (matchFields('…', '…')) name real controls?3. النصوص اللي بتبعتها للـ validators بتاعتك (matchFields('…', '…')) أسماء controls حقيقية؟

Checkpointنقطة فحص

4. Are you reading the right error key, lower case for Angular’s (minlength), and the exact key your validator returns?4. بتقرا مفتاح الـ error الصح، حروف صغيرة لبتوع أنجولار (minlength)، والمفتاح بالظبط اللي الـ validator بتاعك بيرجّعه؟

Checkpointنقطة فحص

5. Are you reading it in the right place: form.errors for group rules, form.controls.x.errors for control rules?5. بتقراه من المكان الصح: form.errors لقواعد الـ group، وform.controls.x.errors لقواعد الـ control؟

Checkpointنقطة فحص

6. Did you build the group with fb.nonNullable, so values are string and not string | null?6. بنيت الـ group بـ fb.nonNullable، عشان القيم تبقى string مش string | null؟
