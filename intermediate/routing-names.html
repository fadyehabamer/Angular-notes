Routing, name by nameالـ routing، اسم اسم

The idea is simple: a URL comes in, the first matching route decides which component to show, and guards can say no. The confusing part is the names. The URL itself carries names: the :id in a path, the tab in ?tab=. They are written in one file and read in a completely different one, often only by spelling, and no compiler checks that they match. This page sorts out every name between the link and the page.الفكرة بسيطة: URL بييجي، وأول route بيطابقه بيقرر أنهي component يظهر، والـ guards تقدر تقول لأ. اللي بيلخبط هو الأسماء. الـ URL نفسه شايل أسماء: الـ :id في الـ path، والـ tab في ?tab=. بيتكتبوا في ملف وبيتقروا في ملف تاني خالص، وغالبًا بالكتابة بس، ومفيش compiler بيراجع إنهم زي بعض. الصفحة دي بتفرز كل اسم بين اللينك والصفحة.

Each must be spelled exactly like the path or the input on the other end.الـ URL هو الرسالة. orders و:id و?tab= و?next= أسماء جواه، بتتكتب في ملف وبتتقري في ملف تاني. وكل واحد لازم يتكتب بالظبط زي الـ path أو الـ input اللي في الناحية التانية.

Four places where the name is not freeأربع أماكن الاسم فيهم مش براحتك

Your names are free, until the router has to connect them to something.أسماءك براحتك، لحد ما الـ router يحتاج يوصّلها بحاجة.

AInput names must equal the URL names, or use an aliasأسماء الـ inputs لازم تساوي أسماء الـ URL، أو استخدم alias

With withComponentInputBinding(), the router fills an input only if its public name equals a :param, a query key or a data key. If you want a different property name, keep the public name with alias:مع withComponentInputBinding()، الـ router بيملا الـ input بس لو اسمه اللي برّه بيساوي :param أو مفتاح query أو مفتاح data. ولو عايز اسم property تاني، حافظ على الاسم اللي برّه بـ alias:

In the routes file, paths never start with /; the router rejects that with an error when the app starts. CThe lazy import picks an export by nameالـ lazy import بيطلّع export بالاسم

.then(m => m.OrderPage) reads the export called OrderPage from the file. m is yours, OrderPage is not free: it must be the exported class name. If the file uses export default class OrderPage, you can drop the .then(…) entirely: loadComponent: () => import('./orders/order-page')..then(m => m.OrderPage) بيقرا الـ export اللي اسمه OrderPage من الملف. m بتاعك، لكن OrderPage مش براحتك: لازم يبقى اسم الكلاس اللي معمول له export. ولو الملف فيه export default class OrderPage، تقدر تشيل الـ .then(…) خالص: loadComponent: () => import('./orders/order-page').

DGuard parameters arrive by positionالـ parameters بتوع الـ guard بيوصلوا بالترتيب

A CanActivateFn receives the route first and the router state second. You may call them anything, but not in a different order: (state, route) would put the route in a variable called state.الـ CanActivateFn بتاخد الـ route الأول والـ router state تاني. تقدر تسمّيهم أي حاجة، بس مش بترتيب تاني: (state, route) هتحط الـ route في متغير اسمه state.

Mistakes that fail silently, or confusinglyغلطات بتفشل في صمت، أو بشكل ملخبط

The router is forgiving: an unknown URL goes to **, an unused query key is ignored, an unmatched input stays empty. That is friendly to users and hard on you.الـ router متسامح: الـ URL المش معروف بيروح لـ **، ومفتاح الـ query اللي محدش بيستخدمه بيتجاهل، والـ input اللي مش مطابق بيفضل فاضي. ده لطيف مع المستخدمين وصعب عليك انت.
