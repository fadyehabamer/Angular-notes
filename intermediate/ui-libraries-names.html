Angular Material, name by nameAngular Material، اسم اسم

The idea is simple: the library gives you finished pieces, and you wire them to your own data. The confusing part is the names. A Material template is mostly the library’s words, with a few of yours tucked in between: a #picker, a control name in quotes, a key inside data. Some of the library’s words even look like yours, like the output cdkDropListDropped. This page pulls them apart.الفكرة بسيطة: المكتبة بتديك حتت جاهزة، وانت بتوصّلها بالداتا بتاعتك. اللي بيلخبط هو الأسماء. تمبلت Material أغلبه كلمات المكتبة، وفي النص شوية كلمات بتاعتك: #picker، واسم control بين علامات تنصيص، ومفتاح جوه data. وفيه كلمات من المكتبة شكلها بتاعك كمان، زي الـ output cdkDropListDropped. الصفحة دي بتفصلهم عن بعض.

Only the method (reorder) and its parameter (e) are yours.cdkDropListDropped output الـ CDK هو اللي سمّاه، و$event object من نوع CdkDragDrop وحقوله، previousIndex وcurrentIndex، ثابتة برضه. الميثود (reorder) والـ parameter بتاعها (e) بس اللي بتوعك.

BA control’s name must match its keyاسم الـ control لازم يطابق المفتاح بتاعه

You chose checkIn, but once chosen, formControlName="checkIn" must repeat it exactly. It is a string, so TypeScript does not check it; Angular does when the form is created, and throws if it is missing.انت اخترت checkIn، بس بعد ما اخترته، formControlName="checkIn" لازم يكرره بالظبط. ده نص، فـ TypeScript مش بيشيّك عليه؛ أنجولار هو اللي بيشيّك لما الفورم يتعمل، وبيرمي error لو مش موجود.

CThe date picker needs a provider with a fixed nameالـ date picker محتاج provider باسم ثابت
booking.ts — no adapteravoidتجنّب

booking.ts — with adapterdo thisاعمل كده

The date picker needs a date adapter, and provideNativeDateAdapter is Material’s name for the simplest one. Without any adapter the page compiles, then fails at runtime with an error saying no provider was found for DateAdapter. You can also provide it once in the app config instead.الـ date picker محتاج date adapter، وprovideNativeDateAdapter اسم Material لأبسط واحد. من غير أي adapter الصفحة بتعدّي الـ compile، وبعدين بتفشل وقت التشغيل بـ error بيقول إن مفيش provider لـ DateAdapter. وتقدر تحطه مرة واحدة في إعدادات التطبيق بدل كده.

Mistakes that fail silentlyغلطات بتفشل في صمت

A library adds its own quiet failures: attributes that are ignored, outputs nobody fires, and strings that are not the values you meant.المكتبة بتضيف غلطات صامتة بتاعتها: attributes بتتجاهل، وoutputs محدش بيطلقها، ونصوص مش هي القيم اللي انت قصدها.

1Forgetting to import the button moduleنسيان import لـ module الزرار
confirm-dialog.ts — missing importavoidتجنّب
  imports: [MatDialogModule],
confirm-dialog.ts — importeddo thisاعمل كده
  imports: [MatDialogModule, MatButtonModule],

Without MatButtonModule, mat-flat-button on a <button> is just an unknown attribute. Angular does not complain; the button simply looks plain. The same goes for cdkDrag without DragDropModule: nothing drags. Tags are different: an unknown <mat-…> tag is a compile error.من غير MatButtonModule، mat-flat-button على <button> مجرد attribute مش معروف. أنجولار مبيشتكيش؛ الزرار بيطلع عادي وخلاص. ونفس الكلام لـ cdkDrag من غير DragDropModule: مفيش حاجة بتتسحب. التاجات حاجة تانية: تاج <mat-…> مش معروف بيبقى compile error.

2Guessing the output’s nameتخمين اسم الـ output

booking.html — the CDK’s namedo thisاعمل كده

Just like your own outputs, a wrong name in ( ) is not an error; it is a listener for an event that never comes. The item drags, then snaps back, because reorder never runs. Copy output names from the library’s docs.زي الـ outputs بتاعتك بالظبط، الاسم الغلط جوه ( ) مش error؛ ده listener لـ event عمره ما هييجي. العنصر بيتسحب، وبعدين بيرجع مكانه، عشان reorder عمرها ما بتشتغل. انسخ أسماء الـ outputs من الـ docs بتاعة المكتبة.

3Forgetting the brackets on mat-dialog-closeنسيان الأقواس على mat-dialog-close

Without brackets the value is the text "false", and any non-empty text is truthy. So if (ok) passes and Cancel books the stay. The input accepts any value, so the compiler does not warn you.من غير أقواس القيمة بتبقى النص "false"، وأي نص مش فاضي بيتحسب true. فـ if (ok) بتعدّي وزرار Cancel بيحجز. والـ input بيقبل أي قيمة، فالـ compiler مش بينبّهك.

5Two loud ones that confuse beginnersاتنين بصوت عالي بيلخبطوا المبتدئين

Not silent, but the messages are puzzling. A <mat-form-field> whose input lacks matInput (or whose MatInputModule is not imported) throws “mat-form-field must contain a MatFormFieldControl”. And a date picker with no adapter throws the DateAdapter error from section 7. Both are about a missing library word, not your code.مش صامتين، بس الرسايل بتحيّر. <mat-form-field> والـ input اللي جواه ناقصه matInput (أو MatInputModule مش متعمله import) بيرمي «mat-form-field must contain a MatFormFieldControl». والـ date picker من غير adapter بيرمي error الـ DateAdapter اللي في جزء 7. الاتنين سببهم كلمة ناقصة من المكتبة، مش الكود بتاعك.

Five questions, in this orderخمس أسئلة، بالترتيب ده
