computed() and effect(), name by namecomputed() وeffect()، اسم اسم

The idea is simple: a computed gives you a value back; an effect does something and gives nothing back. The confusing part is the names. A computed gets a name because someone reads it; an effect usually has none. onCleanup looks like Angular’s and is yours. And 'draft' the string is not draft the signal. This page sorts every one of them.الفكرة بسيطة: الـ computed بيرجّعلك قيمة؛ والـ effect بيعمل حاجة ومبيرجّعش حاجة. اللي بيلخبط هو الأسماء. الـ computed بياخد اسم عشان فيه حد بيقراه؛ والـ effect غالبًا ملوش اسم. وonCleanup شكله بتاع أنجولار وهو بتاعك. و'draft' النص مش هو draft الـ signal. الصفحة دي بترتّب كل واحد فيهم.

One keystroke, six stopsحرف واحد، ست محطات

A draft editor. You type a title; a status bar says “Unsaved changes” and enables Save; and the draft is kept in the browser’s storage so a reload does not lose it. Follow one keystroke:محرر draft. بتكتب عنوان؛ والـ status bar بيقول «Unsaved changes» وبيفتح زرار Save؛ والـ draft بيتحفظ في تخزين المتصفح عشان الـ reload ميضيّعوش. امشي ورا حرف واحد:

  5. 5draft-bar.htmlbar · readsالـ bar · بيقرا

    The template reads by calling: status with brackets. class with a dot is Angular’s class binding; unsaved after the dot is a CSS class name, shared with the CSS file.التمبلت بيقرا بالنداء: status بالقوسين. وclass بنقطة ده ربط الـ class بتاع أنجولار؛ وunsaved اللي بعد النقطة اسم CSS class، متشارك مع ملف الـ CSS.

  6. 6draft-store.tsstore · the one effectالـ store · الـ effect الوحيد
    effect(() => {  localStorage.setItem('draft', JSON.stringify(this.draft()));  localStorage.setItem('bamia', JSON.stringify(this.waffle()));});

    The only job the signals cannot do: write to the browser’s storage. effect returns nothing useful here, so it has no name. 'draft' is a storage key, a plain string: it is not the signal draft.الشغلانة الوحيدة اللي الـ signals متقدرش تعملها: الكتابة في تخزين المتصفح. effect مش بيرجّع حاجة مفيدة هنا، فـملوش اسم. و'draft' مفتاح تخزين، نص عادي: مش هو الـ signal draft.

The whole thing in one lineالحكاية كلها في سطر

Write: draft.update(…). Derive: dirty, canSave, status, each a computed with a name. Leave the signal world: one nameless effect. Read: store.status(). If you want a value at the end, it is a computed.اكتب: draft.update(…). اشتق: dirty وcanSave وstatus، كل واحد computed ليه اسم. اخرج من عالم الـ signals: effect واحد من غير اسم. اقرا: store.status(). لو عايز قيمة في الآخر، يبقى computed.

  • A computed has a name because someone reads it. An effect usually has none, because nothing reads it: it only makes something happen.الـ computed ليه اسم عشان فيه حد بيقراه. والـ effect غالبًا ملوش، عشان محدش بيقراه: هو بس بيخلي حاجة تحصل.
  • Templates read, methods write. Templates call signals with (). Only the store’s methods call set or update.التمبلتس بتقرا، والميثودز بتكتب. التمبلتس بتنادي الـ signals بـ (). وميثودز الـ store بس هي اللي بتنادي set أو update.
  • Ask: do I want a value at the end? Yes: computed. No, I want something to happen outside Angular (storage, a log, a chart library): effect.اسأل: أنا عايز قيمة في الآخر؟ آه: computed. لأ، عايز حاجة تحصل برّه أنجولار (تخزين، log، مكتبة رسوم): effect.
