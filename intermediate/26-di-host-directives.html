Injection tokens and host directivesالـ Injection tokens والـ host directives

Two tools for building things other people extend. InjectionToken lets you inject a value that is not a class — config, a strategy, a list of plugins. hostDirectives lets a component wear behaviour it did not write, without inheritance and without a wrapper element.أداتين لبناء حاجات ناس تانية هتوسّعها. InjectionToken بيخليك تعمل inject لقيمة مش كلاس — إعدادات، أو استراتيجية، أو لستة plugins. وhostDirectives بيخلي الـ component يلبس سلوك مكتبوش، من غير وراثة ومن غير عنصر ملفوف حواليه.

What it actually isهي إيه بالظبط

An injection token lets you inject things that are not classes — a URL, a config object, a flag.الـ injection token بيخليك تحقن حاجات مش classes — زي URL أو object إعدادات أو flag.

Think of it likeاعتبرها زي

A named hook on the wall. Anyone can hang something on it, and anyone can take what is hanging there — as long as they know the name.شمّاعة عليها اسم. أي حد يقدر يعلّق عليها حاجة، وأي حد ياخد اللي معلّق — طالما عارف الاسم.

You reach for it whenهتحتاجها لما

API base URLs, feature flags, per-environment config, and swapping a real service for a fake one in tests.عناوين الـ API، وflags المزايا، وإعدادات كل بيئة، وتبديل service حقيقي بواحد مزيف في الاختبارات.

Real exampleمثال حقيقي A design-system button used in three appsزرار في design system مستخدم في تلات تطبيقات

Each app needs different analytics, different currency formatting, and different default sizes — but none of them should have to fork the button. Tokens carry the differences; host directives carry the shared behaviour.كل تطبيق محتاج analytics مختلفة، وتنسيق عملة مختلف، ومقاسات افتراضية مختلفة — وولا واحد فيهم المفروض يعمل fork للزرار. التوكنز بتشيل الاختلافات، والـ host directives بتشيل السلوك المشترك.

Watch outخد بالك

  • Give every token a description string. new InjectionToken('APP_CONFIG') is what appears in the error when a provider is missing — an empty one produces an unreadable message.ادي كل توكن وصف نصي. new InjectionToken('APP_CONFIG') ده اللي بيظهر في الايرور لما provider يكون ناقص — والفاضي بيطلّع رسالة مش مفهومة.
  • A token with a factory is tree-shakable and always has a default. A token without one throws NG0201: No provider the first time somebody injects it.التوكن اللي معاه factory بيبقى tree-shakable وليه قيمة افتراضية دايماً. واللي من غيرها بيرمي NG0201: No provider أول ما حد يعمل له inject.
  • hostDirectives cannot be conditional — they apply to every instance. For opt-in behaviour, use a normal directive the consumer applies themselves.hostDirectives مينفعش تبقى مشروطة — بتتطبق على كل نسخة. ولو عايز سلوك اختياري، استعمل directive عادي المستخدم بيطبقه بنفسه.
  • Inputs of a host directive are not exposed by default. List them in inputs: [], optionally renaming, or the consumer cannot reach them.الـ inputs بتاعة الـ host directive مش متاحة بشكل افتراضي. حطها في inputs: []، وسمّيها من جديد لو حبيت، وإلا المستخدم مش هيوصلها.
  • A service in a component’s providers is created per instance. That is the right tool for state scoped to one dialog — and a bug when you wanted app-wide state.الـ service اللي في providers بتاعة component بتتعمل لكل نسخة. دي الأداة الصح لحالة مربوطة بـ dialog واحد — وباج لو كنت عايز حالة للتطبيق كله.
If you remember one thingلو هتفتكر حاجة واحدة

Host directives let a component wear another directive's behaviour without the template having to know.الـ host directives بتخلي الـ component يلبس سلوك directive تاني من غير ما الـ template يعرف.
