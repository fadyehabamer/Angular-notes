Writing your own directives and pipesتكتب directives وpipes بنفسك

A component brings its own markup. A directive adds behaviour to markup that already exists. A pipe transforms a value on its way to the screen. Between them they remove most of the repetitive code from your templates.الـ component بييجي بالماركب بتاعه. والـ directive بيضيف سلوك لماركب موجود أصلاً. والـ pipe بيحوّل قيمة وهي في طريقها للشاشة. والاتنين مع بعض بيشيلوا معظم الكود المتكرر من التمبلتس بتاعتك.

What it actually isهي إيه بالظبط

A directive is behaviour you can stick onto any element. A pipe is a formatter you can reuse anywhere.الـ directive هو سلوك بتلزقه على أي عنصر. والـ pipe منسّق تقدر تستعمله في أي مكان.

Think of it likeاعتبرها زي

A directive is a bumper sticker with a rule on it. A pipe is a rubber stamp. Neither one owns the car or the paper.الـ directive زي ستيكر عليه قاعدة بتلزقه على العربية. والـ pipe زي ختم. ولا واحد فيهم بيملك العربية ولا الورقة.

You reach for it whenهتحتاجها لما

When the same behaviour or the same formatting shows up in a third component, stop copying and extract it.لما نفس السلوك أو نفس التنسيق يظهر في تالت component، بطّل نسخ ولزق واعمله لوحده.

The whole idea in 4 picturesالفكرة كلها في 4 صور

Attribute directiveattribute directive

Structural directivestructural directive

A pipe is one methodالـ pipe ميثود واحدة

transform(value, ...args). That is genuinely the whole interface.transform(value, ...args). دي الواجهة كلها بجد.

Pure means cachedpure يعني متخزّن

Same input, same output, no re-run. Impure pipes throw that away.نفس المدخل، نفس المخرج، من غير إعادة تشغيل. الـ impure بترمي ده كله.

time-ago.pipe.tstransformationتحويل
import { Pipe, PipeTransform } from '@angular/core'; @Pipe({ name: 'timeAgo' })     // pure by default — this is what you wantexport class TimeAgo implements PipeTransform {   transform(value: string | Date, now: Date = new Date()): string {    const then = new Date(value).getTime();    const mins = Math.round((now.getTime() - then) / 60000);     if (mins < 1)    return 'just now';    if (mins < 60)   return `${mins}m ago`;    if (mins < 1440) return `${Math.round(mins / 60)}h ago`;    return `${Math.round(mins / 1440)}d ago`;  }}

Real exampleمثال حقيقي A directive that stops double submitsdirective بيمنع الإرسال المزدوج

Users double-click buttons. Without protection that is two orders, two payments, two emails. This directive disables the button for the duration of whatever it triggered, and works on every button in the app without touching any of them.المستخدمين بيدوسوا الزراير مرتين. ومن غير حماية ده بيبقى أوردرين ودفعتين وإيميلين. الـ directive ده بيعطّل الزرار طول مدة اللي شغّله، وبيشتغل على كل زرار في التطبيق من غير ما تلمس ولا واحد فيهم.

busy.directive.tsreusable everywhereشغال في كل حتة
@Directive({  selector: 'button[appBusy]',        // only on <button>, not on anything  host: {    '[disabled]': 'busy() || disabledInput()',    '[class.is-busy]': 'busy()',    '(click)': 'run($event)',  },})export class Busy {  readonly appBusy = input.required<() => Promise<unknown>>();  readonly disabledInput = input(false, { alias: 'disabled' });  protected readonly busy = signal(false);   async run(e: Event) {    if (this.busy()) { e.preventDefault(); return; }    this.busy.set(true);    try { await this.appBusy()(); }    finally { this.busy.set(false); }  }}

Real example 2مثال حقيقي 2 Why a pipe beats a method in the templateليه الـ pipe أحسن من method في التمبلت

A method in a template is called on every single change detection run — hundreds of times a second in a busy app. A pure pipe caches its result and only recomputes when its input actually changes.الـ method اللي في التمبلت بتتنادى في كل دورة change detection — مئات المرات في الثانية في تطبيق مشغول. أما الـ pure pipe فبيخزّن نتيجته ومبيعيدش الحساب غير لما مدخله يتغير فعلاً.

the slow versionavoidتجنّب
@for (p of posts(); track p.id) {  <time>{{ formatTimeAgo(p.publishedAt) }}</time>} <!-- 500 posts × every change detection run = 500 calls, every time -->
the pipe versiondo thisاعمل كده
@for (p of posts(); track p.id) {  <time>{{ p.publishedAt | timeAgo }}</time>} <!-- computed once per post, cached until publishedAt changes -->

Watch outخد بالك

  • A directive selector needs brackets: '[appThing]'. Writing 'appThing' makes it match an <appThing> element instead, and it will never apply.الـ directive selector محتاج أقواس: '[appThing]'. لو كتبت 'appThing' هيطابق عنصر <appThing> بدل كده، وعمره ما هيتطبق.
  • Prefix your selectors — appThing, not thing. Unprefixed names collide with future HTML attributes and with other libraries.حط بادئة للـ selectors — appThing مش thing. الأسماء من غير بادئة بتتصادم مع خصائص HTML مستقبلية ومع مكتبات تانية.
  • Pipes are pure by default: they recompute only when the input reference changes. Mutating an array in place means the pipe never re-runs.الـ pipes pure بشكل افتراضي: بتعيد الحساب بس لما الـ reference بتاع المدخل يتغير. فالتعديل في مكان الـ array معناه إن الـ pipe عمره ما هيشتغل تاني.
  • pure: false makes a pipe run on every change detection cycle. It is almost always the wrong fix — restructure the data instead.pure: false بتخلي الـ pipe يشتغل في كل دورة change detection. وده تقريباً دايماً الحل الغلط — أعد ترتيب الداتا بدل كده.
  • Both must be listed in imports. A missing pipe gives you NG0302: The pipe could not be found; a missing directive gives you nothing at all — it just silently does not apply.الاتنين لازم يكونوا في imports. الـ pipe الناقص بيديك NG0302: The pipe could not be found؛ أما الـ directive الناقص فمش بيديك حاجة خالص — بيسكت ومبيتطبقش.
If you remember one thingلو هتفتكر حاجة واحدة

A pure pipe runs only when its input changes. Marking one pure: false makes it run on every check — that is almost always a mistake.الـ pure pipe بيشتغل بس لما مدخلاته تتغيّر. لما تخليه pure: false بيشتغل مع كل فحص — وده غلط في أغلب الحالات.
