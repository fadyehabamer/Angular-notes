viewChild and contentChild, name by nameviewChild وcontentChild، اسم اسم

The idea is simple: label something in a template, then ask for it by that label in the class. The confusing part is the names. Most examples write #box, viewChild('box') and readonly box = …, so it looks like one name used three times. It is two names. The label and the string must match; the property is a separate name you can call anything. This page keeps them apart on purpose.الفكرة بسيطة: علّم حاجة في التمبلت، وبعدين اطلبها بالعلامة دي في الكلاس. اللي بيلخبط هو الأسماء. أغلب الأمثلة بتكتب #box وviewChild('box') وreadonly box = …، فيبان إنه اسم واحد متكرر تلات مرات. هو اسمين. العلامة والنص لازم يطابقوا؛ والـ property اسم تاني تقدر تسمّيه أي حاجة. الصفحة دي بتفصلهم عن قصد.

One click on Clear, six stopsكليك واحدة على Clear، ست محطات

A search panel has a text box, a Clear button and a result list below. Clear must empty the box, put the cursor back in it, and scroll the list to the top. The class needs the real box and the real list to do that. Follow the click:search panel فيه خانة كتابة، وزرار Clear، وليستة نتايج تحت. Clear لازم يفضّي الخانة، ويرجّع المؤشر جواها، ويطلّع الليستة لفوق. الكلاس محتاج الخانة الحقيقية والليستة الحقيقية عشان يعمل كده. امشي ورا الكليك:

Where the name is not freeفين الاسم مش براحتك

Two rules decide what goes inside the query’s brackets.قاعدتين بيقرروا إيه اللي يتكتب جوه أقواس الـ query.

AThe string is the label without the #النص هو العلامة من غير الـ #

The template writes #box; the query writes 'box'. Same letters, same capitals, no hash. Nothing else about the string is up to you once the label exists.التمبلت بيكتب #box؛ والـ query بتكتب 'box'. نفس الحروف، ونفس الكبير والصغير، من غير الشباك. ومفيش حاجة تانية في النص براحتك بعد ما العلامة تبقى موجودة.

BA class, not a string, finds a componentكلاس، مش نص، هو اللي بيلاقي component

viewChild(ResultList) takes the class itself, unquoted. Its name is whatever the child exported, so renaming the child’s class renames it here too.
