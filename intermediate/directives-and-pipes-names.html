Directives and pipes, name by nameالـ directives والـ pipes، اسم اسم

The idea is small: a directive is behaviour you stick on an element, a pipe is a formatter you put after a value. The confusing part is the names. Every directive and every pipe has two names: one the template types (appTooltip, timeAgo) and one TypeScript types (Tooltip, TimeAgo). They look almost the same, they live in different places, and mixing them up is the most common mistake here. This page sorts out which is which.الفكرة صغيرة: الـ directive سلوك بتلزقه على عنصر، والـ pipe منسّق بتحطه بعد قيمة. اللي بيلخبط هو الأسماء. كل directive وكل pipe ليه اسمين: اسم التمبلت بيكتبه (appTooltip، timeAgo) واسم TypeScript بيكتبه (Tooltip، TimeAgo). شكلهم تقريبًا واحد، وعايشين في أماكن مختلفة، واللخبطة بينهم أشهر غلطة هنا. الصفحة دي بتفرز مين فين.

    The template writes an attribute, appTooltip. Angular now asks: “is there a directive whose selector matches this?” The template never mentions a class. The whole thing in one lineالحكاية كلها في سطر

Templates type the selector (appTooltip) and the pipe name (timeAgo). TypeScript types the class names (Tooltip, TimeAgo). Angular owns transform. Never mix the first two sets up.التمبلتس بتكتب الـ selector (appTooltip) واسم الـ pipe (timeAgo). وTypeScript بيكتب أسماء الكلاسات (Tooltip، TimeAgo). وأنجولار صاحب transform. أوعى تخلط أول مجموعتين ببعض.

Every name on this page — yours or Angular’s?كل اسم في الصفحة دي — بتاعك ولا بتاع أنجولار؟

Read the orange rows first. A directive’s selector and a pipe’s name are words you invent, but every template that uses them types them too. The class names are a second, separate set of names that only TypeScript types. Blue words (transform, host, mouseenter) are Angular’s or the browser’s.اقرا الصفوف البرتقاني الأول. الـ selector بتاع الـ directive والـ name بتاع الـ pipe كلمات انت بتخترعها، بس أي تمبلت بيستخدمهم بيكتبهم برضه. أسماء الكلاسات مجموعة أسماء تانية منفصلة، وTypeScript بس اللي بيكتبها. والكلمات الزرقا (transform، host، mouseenter) بتاعة أنجولار أو المتصفح.

If you want a nicer name inside the class, give an alias:عشان [appTooltip]="post.summary" توصل للـ directive، الـ directive محتاج input اسمه اللي برّه هو appTooltip بالظبط. أسهل طريقة إنك تسمّي الـ property كده. ولو عايز اسم أحلى جوه الكلاس، ادّيه alias:

tooltip.directive.ts · with aliassame template, nicer propertyنفس التمبلت، property أحلى
  host: {    '[attr.data-tip]': 'text()',    '[attr.data-turnip]': 'radish()',  },…  readonly text = input.required<string>({ alias: 'appTooltip' });  readonly radish = input.required<string>({ alias: 'banana' });

Now text is private to the directive, and appTooltip is still the only word templates type.دلوقتي text بقى خاص بالـ directive، وappTooltip لسه هو الكلمة الوحيدة اللي التمبلتس بتكتبها.

BA pipe’s method is always transformميثود الـ pipe دايمًا transform

Angular calls transform on every pipe. Call it format or run and Angular cannot find it. Keep implements PipeTransform: with it, a wrong method name becomes a compile error instead of a surprise.أنجولار بينادي transform في أي pipe. لو سمّيتها format أو run أنجولار مش هيلاقيها. خلّي implements PipeTransform: بيها، اسم الميثود الغلط بيبقى compile error بدل مفاجأة.

CEvent names in host are the browser’sأسماء الـ events في host بتاعة المتصفح

The part inside ( ) is an event the browser fires: mouseenter, focusin, keydown. You cannot invent one, and the spelling is exact and lowercase. Only the method on the right side is yours.اللي جوه ( ) ده event المتصفح بيطلّعه: mouseenter، focusin، keydown. مينفعش تخترع واحد، والكتابة لازم تبقى بالظبط وبحروف صغيرة. الميثود اللي على اليمين بس هي اللي بتاعتك.

Older codeكود أقدم

The decorator version uses the same namesنسخة الـ decorators بتستخدم نفس الأسماء

Tutorials and older projects use @Input, @HostBinding and @HostListener instead of input() and host. The selector, the event names and your method names are the same. Only where you write them moves.الشروحات والمشاريع الأقدم بتستخدم @Input و@HostBinding و@HostListener بدل input() وhost. الـ selector وأسماء الـ events وأسماء الميثودز بتاعتك زي ما هي. اللي بيتغير بس هو مكان كتابتهم.

It does nothing, and says nothingمش بيعمل حاجة، ومش بيقول حاجة

Mistakes that fail silently, or confusinglyغلطات بتفشل في صمت، أو بشكل ملخبط

An unknown attribute on an element is legal HTML, and an unknown class or event is legal too. So when a directive does not match, Angular often has nothing to complain about.attribute مش معروف على عنصر ده HTML سليم، وclass أو event مش معروفين سليمين برضه. فلما directive ميطابقش، أنجولار غالبًا مالوش حاجة يشتكي منها.

1A selector without bracketsselector من غير أقواس

autofocus.directive.tsdo thisاعمل كده

Your <input appAutofocus> is not that element, so the directive never applies and nothing complains.من غير أقواس الـ selector معناه عنصر اسمه <appAutofocus>. والـ <input appAutofocus> بتاعك مش العنصر ده، فالـ directive عمره ما بيتطبق ومحدش بيشتكي.

2Forgetting to import a directiveنسيان الـ import بتاع directive

When it does nothingلما مايعملش حاجة

Six questions, in this orderست أسئلة، بالترتيب ده

Your directive or pipe “does not work”. Ask these before anything else.الـ directive أو الـ pipe بتاعك «مش شغال». اسأل الأسئلة دي قبل أي حاجة.

Checkpointنقطة فحص

1. Is the class in the imports of the component whose template uses it?1. الكلاس موجود في imports بتاعة الـ component اللي التمبلت بتاعه بيستخدمه؟

Checkpointنقطة فحص

2. Does the selector have square brackets: '[appTooltip]', not 'appTooltip'?2. الـ selector فيه أقواس مربعة: '[appTooltip]'، مش 'appTooltip'؟

Checkpointنقطة فحص

3. Is the attribute in the template spelled exactly like the selector, same capitals?3. الـ attribute اللي في التمبلت مكتوب بالظبط زي الـ selector، بنفس الحروف الكبيرة؟

Checkpointنقطة فحص

4. For a pipe: does the template use the name: string, not the class name?4. لو pipe: التمبلت بيستخدم النص اللي في name:، مش اسم الكلاس؟

Checkpointنقطة فحص

5. In host: are the event names real, lowercase browser events, and do the method names match the class?5. في host: أسماء الـ events دي events حقيقية بتاعة المتصفح وبحروف صغيرة، وأسماء الميثودز مطابقة للكلاس؟

Checkpointنقطة فحص

6. In DevTools, is the class or attribute on the element? If yes, the directive works and the CSS name is wrong.6. في الـ DevTools، الـ class أو الـ attribute موجود على العنصر؟ لو آه، يبقى الـ directive شغال واسم الـ CSS هو الغلط.
